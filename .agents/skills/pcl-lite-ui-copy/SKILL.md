# PCL-Lite UI Copy Style

编写或修改 `PCL.Core/App/Localization/Languages/{zh-CN,zh-TW,en-US}.xaml` 及页面硬编码提示时遵守以下规则：

## 1. 普通功能文案：短、直白、去技术黑话
- 只写 **“这是什么 / 怎么用 / 会带来什么明显影响（如功耗、覆盖）”**，控制在一到两句短句内。
- **删除底层实现细节**：不要在普通用户界面出现 `WGC`、`Pixel Shader`、`DIP`、采样排除逻辑、拖动时渲染细节、技术性免责声明等与使用无关的内容。
- **删除废话与重复兜底**：去掉“无需等待，确认后立即生效”“不影响其他无关设置”“不修改源文件”等冗长措辞。

## 2. 必须与代码实际行为一致
- **不虚构自动化行为**：如果必须点按钮才会复制或执行，禁止写成“已自动复制”；应明确写出操作方式（例如“请点击下方「复制回执码」…”）。
- **保留关键副作用与前置条件**：例如覆盖更新保留市场关联、模组索引涵盖范围及已有版本需手动创建等关键事实，用一句话写清，不要省略。

## 3. 崩溃分析、报错与 Debug 信息：保持详细
- `Crash.*`、`LogPage.*`、`Config.Error.*`、失败堆栈、校验错误（密钥不匹配、文件损坏、网络错误）与安全警告**保留完整排查信息与操作指引**，不精简。

## 4. 三语同步与校验
- 修改或新增文本时同步更新 `zh-CN.xaml`、`zh-TW.xaml`、`en-US.xaml`。
- 保持 `{0}`、`{1}`、`{2}` 等格式化占位符与换行符（`&#xA;`）完全一致，并保证 XML 合法。
- 修改后运行：
  - `dotnet run --project tools/UiSmoke/UiSmoke.csproj`
