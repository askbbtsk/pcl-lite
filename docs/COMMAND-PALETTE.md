# 全局搜索 / 命令面板

按 **Ctrl+K**，或点击窗口右下角的搜索按钮打开。再次按 Ctrl+K、按 Esc 或点击面板外侧关闭。确认和登录弹窗显示期间不会打开搜索。

- 搜索当前 Minecraft 目录里已加载的可见实例，打开结果进入对应实例管理；若当前已在实例管理概览页切换到另一实例，会同步刷新顶栏标题、左侧边栏与概览页内容；损坏实例沿用实例列表的行为，改为打开文件夹。不会直接启动游戏或改变主页选中实例。
- 搜索设置页面和常用导航操作，自动遵守启动器现有的功能隐藏配置（以及 `F12` 临时显示隐藏功能的开关）。支持标题、关键词及空格分隔的多个条件，不区分英文大小写；例如 `Java`、`内存`、`背景`、`language`。
- 搜索**打开面板时主页选中实例**的已安装模组，包含 `.disabled` / `.old` 禁用文件。匹配模组名称、Mod ID 和文件名；打开结果在资源管理器中定位文件。未选实例时仍可搜索页面和已加载实例。
- 使用 ↑ / ↓ 选择，Enter 打开，也可单击结果；右上角关闭按钮采用启动器 `MyButton` 控件，支持 Tab 聚焦后按 Enter / Space 关闭面板而不误触当前选中结果。搜索框支持中文输入法；每次最多展示 60 项，输入更具体的关键词缩小范围。

实例列表复用启动器已加载的结果，打开搜索不会强制扫描所有游戏目录。模组只读取当前实例实际运行目录的 `mods` 顶层文件，不递归搜索，也不访问远程平台。名称和 Mod ID 在后台通过现有本地模组解析器读取（启用 `DeferJijOnMiss` 与取消上下文，不在缓存未命中时解压完整 Jar-in-Jar 内嵌树），损坏文件退回文件名；关闭面板会取消后续扫描，重新打开重新读取。

首版设置结果定位到设置页面，不定位到单个开关；模组结果定位文件，不执行启用、禁用或删除操作。搜索不改写游戏文件，不自动安装或清理内容。搜索结果过期、目录权限不足或文件被移走时给出提示。

## 验证

匹配排序、多词匹配、结果上限、同名项目区分、实例切换刷新、延后 Jar-in-Jar 扫描与取消、功能隐藏过滤及关闭按钮键盘交互由 `CommandPaletteSearchTests` 覆盖：

```powershell
dotnet test PCL.Core.Test/PCL.Core.Test.csproj --filter FullyQualifiedName~CommandPaletteSearchTests
dotnet build "Plain Craft Launcher 2/Plain Craft Launcher 2.csproj" -c Debug
```

桌面验收：在主页、设置页和实例管理页分别打开面板，检查输入焦点、方向键、回车、Esc、Tab 循环和关闭后的焦点恢复；确认回车不会穿透到主页启动按钮。切换语言和深浅主题后重新打开；检查无结果、无选中实例、大量模组、长文件名、关闭后立即重开，以及确认弹窗抢占时的行为。
