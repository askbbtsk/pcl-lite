# 实例修改与界面可靠性修复（dev）

本轮只推 dev，不自动合入 main，不发布。修复依据实际触发路径，不将报告中未证实的影响当作事实。

## 八项核对结果与处理

1. **继承循环**：`McInstance.JsonObject` 在整个同步递归调用链上登记规范化路径，大小写不敏感；重复路径或超过 64 层继承抛出明确异常。异常跨父实例传播，不能被内层“合并失败”日志吞掉；失败时清除未完成的 JSON 缓存。合并时克隆父 JSON，保留现有数组/字段合并规则。这里不声称原实现存在“污染所有实例全局缓存”的证据。
2. **Minecraft 根目录**：修改入口与任务都从实际实例目录验证 `versions/<实例>` 所属根目录；当前全局目录不匹配时，修改前拒绝并提示上下文已变化。旧下载/库解析仍有全局目录依赖，因此不伪装成已经支持任意跨根目录原地修改。插件若打开另一个根目录，应先切换宿主目录。旧重置路径的目标目录使用实际实例路径。
3. **同加载器升级**：全部“修改”操作统一走 `InstanceModificationRunner` 的系统 Temp 暂存、产物校验、事务提交和失败回滚；只在 Minecraft 版本或加载器类型变化时询问是否迁移模组。Fabric API、Legacy Fabric API、OptiFabric 的明确替换与核心 JSON/JAR 纳入同一事务，旧字节保留为禁用备份；不再在提交前删除旧 API。同一源 API 不同时交给通用迁移和显式 API 替换。
4. **重置提示**：重置保留自己的确认，说明备份位置及手改核心文件可能被替换；不再经过“修改加载器”的 5 秒确认。修改加载器仍保留原有备份确认和 5 秒等待，模组迁移的 3 秒确认不取消。
5. **Java 选择**：保留确认文案已告知的目标环境自动 Java 选择，不将其误称“静默覆盖”并改变规则。其他用户设置继续通过现有 INI 编辑器保留。
6. **链接防护**：保留祖先目录 Junction/Symlink 拒绝策略，不等同于禁止普通跨分区目录。普通异常仍由现有增强读取/操作入口捕获；本轮不放宽写入边界。
7. **零项迁移**：增加明确的 `allowEmptySelection` 多选重载，仅迁移预览调用启用。确定全不选返回空列表，取消仍返回 null；原有多选签名、默认值和至少选一项的行为保留。
8. **动画资源**：`AaColor` 目标资源从动画目标控件查找，遵循控件/样式/页面/窗口/应用的 WPF 资源查找规则；不再绕过插件局部和玻璃窗口资源。动画完成恢复 DynamicResource 的规则不变。

## 液态玻璃附带修复

- 侧栏反馈等导航的刷新按钮向胶囊内侧收进，文字同时保留操作区域；关闭玻璃恢复原始按钮边距。
- 收到 `WM_ENTERSIZEMOVE` 后暂停并退役桌面采集、清除采样源，改用静态磨砂材质。移动和缩放期间不连续重建显示器会话；`WM_EXITSIZEMOVE` 后重建并等待新帧恢复折射。关闭玻璃或隐藏窗口时仍走正常清理，不能因松手而重新启用已关闭的采集。
- 外部截图兼容本轮不实施，实时桌面模式的窗口截图排除保持现状。DXGI 及前一轮不透明度行为不回退。

## 验证边界

- 测试编译并执行当前源码中的 JSON getter，验证循环、深度上限、失败后的重新读取、正常合并和父 JSON 不被子项就地修改；替换的仅是启动、日志与文件读取周边。
- 测试事务取消、过期预览、旧 API 与核心同步提交、禁用后缀、存档和用户配置保留；不把这些替代真实 Forge/Fabric/LabyMod 网络安装验收。
- STA 生命周期测试验证拖动暂停、旧帧拒绝、松手恢复和拖动中关闭；资源测试验证插件局部、页面、窗口颜色查找优先级。
- 完整 UI 焦点、不同显卡、多显示器和真实加载器安装仍需桌面验收，CI 构建通过不代表这些硬件路径已全部实测。
