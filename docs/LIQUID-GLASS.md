# PCL Lite LiquidGlass Core

## PR #17 参数控制

- 保留该 PR 的双采样玻璃外观。折射强度范围为 0–200%，每步 1%；100% 保留默认强度，0% 不产生折射位移；旧配置高于新上限时按 200% 呈现。
- 桌面采样率与按钮动画帧数独立，分别支持 30–240 FPS 与不限制；拖动窗口时仍使用桌面采样率，不临时降低或冻结。未配置新采样率的旧用户先沿用原帧率。
- 推荐配置只在主动选择时填入参数。手动调整任一玻璃参数后显示“自定义”，保留其他参数；重新进入设置不覆盖已保存值。推荐配置不会自行授予桌面采样确认。
- 开放基础模糊（0–32 DIP）、磨砂（0–24 DIP）、折射（0–200%）、色散、高光、漫反射、边缘清晰度、玻璃染色比例及按钮动效。染色比例仅缩放玻璃材质染色，不改变背景透明度。
- 新滑块及选择框最小高度为 38 DIP，文案覆盖简体中文、繁体中文和英语。
- “滑稽彩”和“欧皇彩”每次启动分别生成一次随机色相，普通配色和玻璃共用各自的结果；本次运行内不因切换页面而重新随机，不改写保存的用户色相，保留各自渐变形态。
- “恢复玻璃默认参数”需二次确认，只恢复均衡玻璃参数。取消不修改，玻璃与桌面折射开关、授权记录和所有非玻璃设置保持原样。
- 卡片染色／不透明度单独支持 0–100%，只改变卡片底色的 Alpha，不改变文字、图标或玻璃材质；未设置时保留新玻璃原有深浅色卡片透明度。
- 桌面采样质量支持 25–100% 的宽高比例，50% 的采样图像像素数约为四分之一。采样线程在交付帧前以 HALFTONE 缩小图像，WPF 直接上传低分辨率图像并在原区域显示，不在 UI 线程重新扩成原尺寸。Windows 原始捕获仍有全尺寸中间缓冲，降低质量不代表捕获总开销按像素比例下降。原物理采样位置、圆角裁切与截图行为不变。
- 边缘抗锯齿可开关并选择低／标准／高质量；质量调节玻璃轮廓覆盖宽度，关闭后使用硬边，不影响文字和图标的正常抗锯齿。Minecraft 根目录选择项也使用圆角玻璃选中层；启用玻璃时清除列表项整行底色，退出玻璃时恢复原主题背景，避免圆角外露出方形染色块。

原 `UiTahoeGlassEnabled` / `UiTahoeDesktopBackdrop` 配置键和控件类型保留兼容；
主实现与文件统一为 `LiquidGlassCore.cs`、`LiquidGlass*.cs` 和 `Resources/LiquidGlass/`。
旧实验配置没有新的性能与桌面采样确认标记时不能自行启用。

默认折射启动器背景，可正常截图和录屏，不设置 HWND 截图排除。没有背景图片时显示静态材质。
“实时折射桌面”默认关闭，单独开启还需确认持续采样的性能开销。当前使用 Windows Magnification 辅助窗口采样真实桌面，排除仅作用于采样输入中的启动器与辅助窗口，不设置全局截图排除；WGC 后端已移除，DXGI 的旧互操作实现不作为当前采样后端。

玻璃开启时该滑块只调整背景颜色层与壁纸层（0–100%），窗口、文字、玻璃及采样图像保持独立，避免背景变淡时玻璃一起淡化。
玻璃关闭后恢复原来的整体窗口不透明度（40–100%），不改写用户原有配置值。
侧栏标题、路径和启动说明样式在关闭玻璃时使用动态主题前景色，避免夜间模式回落到 WPF 默认黑字。

外部截图和录屏可以捕获启动器，不使用 WGC 黄色采集边框。失败与退出会退役采样会话并隐藏、销毁辅助窗口。辅助窗口仍需参与桌面合成才能取得持续更新，不能简单移到屏幕外来掩盖边角。

玻璃模式下同时处理两层原生边界：辅助采样窗口按内容圆角内缩一个物理像素；启动器 HWND 按实际内容变换后的圆角轮廓裁剪，排除外层 10 DIP 空白边距。后者独立于 WPF 的视觉 Clip，不调整 WindowChrome 的 GlassFrameThickness，避免再次引入系统白圈。裁剪跟随 DPI、尺寸和启动动画；普通拖动不因屏幕坐标变化重建几何。关闭玻璃后恢复最新的原生窗口区域，保留窗口缩放操作。原生调用失败时记录诊断并停止该裁剪，不让异常中断主窗口。

## 性能设置

### 移动窗口时的材质

移动或缩放窗口期间保留玻璃与实时桌面采样，采样帧率与用户滑块设置相同，包括不限制，不再额外限制为 60 FPS。只移动位置时复用图像缓冲，尺寸改变时重建；辅助窗口依据同一批次测得的内容偏移跟随主窗口，避免迟到帧将辅助窗口移到主窗口外。

预设框及选项最小高度 38 DIP，开关高 32 DIP，关闭时设置折叠于开关下。

| 预设 | 模糊 | 色散 | 高光 | 按压动效 | 默认效果帧率 |
| --- | ---: | ---: | ---: | --- | ---: |
| 低消耗 | 0 DIP | 0 | 0.35 | 关闭 | 30 FPS |
| 均衡 | 1 DIP | 0.08 | 0.50 | 开启 | 60 FPS |
| 高画质 | 2 DIP | 0.20 | 0.65 | 开启 | 90 FPS |
| 极致 | 3 DIP | 0.30 | 0.80 | 开启 | 120 FPS |

原生滑块可选 30–240 FPS，最右端不限制。切换预设会应用该档默认帧率，之后可独立修改。
上限作用于桌面回读/上传及按压动画，不修改 Minecraft 帧率，不保证实际渲染达到设置值；
移动/缩放不绕过上限，不限制仍受系统采集和显示器刷新率约束。
开销只作相对预估，不填造 CPU 百分比或内存数值，硬件、分辨率、多屏、动态背景均会影响结果。

个性化的“功能隐藏 → 主页面”同时提供插件市场选项（`UiHiddenPagePlugins`，默认 false）。
勾选即隐藏顶部及折叠区域的插件入口，取消恢复，选择跨启动保存；只是隐藏入口，不关闭插件运行。
沿用临时显示隐藏功能和现有标题栏可见页计数，不把隐藏的插件市场重新放进折叠菜单。

## 来源与参数

- 视频：[BV1PuuEzaEzj](https://www.bilibili.com/video/BV1PuuEzaEzj/)，03:52 最终片段。
- Android：[Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)，参考提交 `65ab177e90e5c1d8c62e70cf7755841982da65f6`。
- 外观参考：macOS Tahoe 工具栏、胶囊操作与侧栏；实现使用 C# / WPF / HLSL。

圆形内部采用视频的公式：

```text
offset = -normal * 0.05 * (d / r)^8
```

圆角矩形采用 Android 的 rounded rectangle SDF 与法线，令 `ratio = clamp(1 + signedDistance / radius, 0, 1)`。
因此半径 100 DIP 的 200 × 200 圆内，该公式与视频等价；圆角矩形、坐标变换与模糊是宿主扩展。
`0.05` 是完整背景的 UV 系数，并非固定 12 DIP；例如背景宽 1000 DIP 时，水平方向最大位移为 50 DIP。
视频未展示 `blur()` 函数体，本实现使用权重归一的九点高斯采样，默认半径 2 DIP。
Android 自身的 `circleMap()` 没有沿用，折射曲线按要求使用八次幂。

按压参考 `LiquidButton.kt` 与 `InteractiveHighlight.kt`：

| 参数 | 数值 |
| --- | --- |
| 弹簧阻尼比 / 刚度 | 0.5 / 300 |
| 基础扩张 | 4 DIP |
| 拖动位移 | `minDimension * tanh(0.05 * offset / minDimension)` |
| 按压白色叠层 | `0.08 * progress` |
| 径向高光 | `0.15 * progress` |
| 按钮染色 | 0.10；悬停 0.14 |

导航、胶囊操作及桌面模式的窗口外层染色为 0.10，侧栏为 0.20；阅读卡片采用中性内容表面。标签、按钮文字和页面内容不进入着色器。
主要操作通过透明蓝色叠层标识，表单采用轻透明填充和细边框，避免实色填充盖住背景。
默认字体使用本机 Segoe UI Variable Text，中文回退 Microsoft YaHei UI；尊重用户自定义字体，没有随程序分发 SF Pro。
内置蓝青曲线背景已移除。关闭桌面采样时仍可折射用户自行配置的启动器壁纸。
这是公开算法在 Windows 上的实现，不等同于 Apple 私有渲染器的逐像素输出。

## 渲染与生命周期

### 当前 dev 的 DXGI 后端与背景分层

- 直接调用 Windows 自带 DXGI / D3D11。`LiquidGlassDxgiDuplication` 封装工厂、显卡输出枚举、桌面复制及帧获取/释放；`LiquidGlassD3D11` 负责设备、纹理和区域回读。移除 WGC、Windows SDK Contracts、CsWinRT 和生成配置，不保留失败后回退 WGC 的逻辑。
- 每个显示器使用所属显卡创建 D3D11 设备，避免混合显卡跨设备复制。每帧 `AcquireNextFrame` 最多等待 20 ms，成功后在 finally 中 `ReleaseFrame`；超时不是错误。设备丢失、显示器切换等走现有有限重建机制。
- 复制帧在释放前保存到本会话持有的 GPU 纹理；桌面静止但窗口移动时仍可重新裁剪。帧率、最多一份待呈现帧及像素缓冲复用保持生效。支持 0/90/180/270 度显示器方向，按行距读取并将桌面 alpha 归一为不透明。
- CI 对两种架构检查正式 EXE 不超过 30,000,000 字节。保留依赖现有 .NET Desktop Runtime 的单文件发布方式，不捆绑运行时，不启用全程序裁剪。
- 主题背景由 `LauncherBackgroundLayer` 唯一持有；父级 `PanForm` 不再重复绘制不透明背景。开启液态玻璃时，不透明度滑块只调整主题背景和图片/视频背景。实时桌面采样、玻璃、文字及 PCL Lite 徽标不随之变淡。关闭玻璃时恢复原有整窗不透明度语义。
- 深色玻璃使用深色衬色，浅色玻璃使用白色衬色；桌面模式增加衬色强度，使黑色桌面在浅色模式下不再原样表现成深色材质，反之亦然。取样像素本身不反色，普通壁纸模式保持原材质强度。
- 回归测试覆盖真实窗口 XAML 的图层结构、背景混合像素、切回普通模式、WARP 纹理复制、DXGI ABI、旋转裁剪和原生帧获取/释放。无可用桌面的 CI 环境会明确跳过真实帧测试，不将其报告为实机通过。多显示器/混合 DPI/显卡视觉矩阵仍需验收。

- `TahoeBackdrop` 只包含桌面采样像素或用户背景图片/视频，与玻璃层相互独立。
- 桌面采集按显示器与窗口交集建立会话，GPU 只回读交集区域；有界帧队列、用户帧率上限、复用像素缓冲、跳过相同帧。最小化/隐藏释放会话，恢复后重建；坐标使用实际屏幕像素及 WPF 变换。
- 坐标通过不可变区域快照无锁发布，原生会话在工作线程退役；UI 不等待 GPU 回读或桌面帧超时。每个会话最多只有一份待呈现帧；缓冲比较后仅上传发生变化的行带，连续内存一次复制。
- 监听显示器拓扑变化并重新枚举；旧会话的帧和失败回调按身份隔离。失败最多自动重试三次，耗尽后停止定时器；显示器变化或重新开关可重试，单块健康显示器不会重置故障显示器的重试预算。
- 采样未就绪时不给控件提供虚假的可折射背景；设置页实时显示等待、工作、暂停、恢复、失败及模糊兼容状态。
- `TahoeGlassSurface` 排除自身、祖先、后代及跨窗口背景；无效源显示静态材质。
- `VisualBrush` 只采样当前控件附近区域，按位移与模糊外扩；局部坐标和法线变换到背景坐标，支持旋转、镜像和缩放。
- 源 alpha 按 WPF 预乘规则保留；Shader 采样夹紧边界。
- 不支持 ps_3_0 时退回背景模糊、染色和固定描边；高对比模式使用不透明材质。
- 布局、源和祖先变换改变时更新坐标；隐藏或卸载解除观察并释放画刷。
- 普通 LayoutUpdated 不再重复构建祖先列表与变换集合；同一帧的连续变换合并更新采样参数，卸载时取消排队更新。
- 按钮弹簧只在未收敛时订阅 Rendering，遵循系统减少动画设置。
- Android Apache 2.0 完整许可与来源随 `Resources/LiquidGlass/NOTICE.txt` 嵌入。
