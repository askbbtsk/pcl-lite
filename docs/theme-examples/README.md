# 编辑你的第一个 PCL Lite XAML 主题

从 [StarterTheme.xaml](StarterTheme.xaml) 开始。它是可以直接拖入安装的单文件主题，中文注释说明了参数、按钮状态、卡片阴影、输入框部件和图标替换。

1. **复制文件**，例如改名为 `MyTheme.xaml`。右键 → 打开方式 → 记事本、VS Code 或其他纯文本编辑器。不要使用 Word。
2. 先改 `Pcl.Theme.Button.CornerRadius` 的 `12` 和 `Pcl.Theme.Learn.Accent` 的颜色。保留 XML 标签、引号和 `x:Key`。
3. 按 **Ctrl+S**，保存为 **UTF-8 的 `.xaml`**，不要变成 `.xaml.txt`。Windows 中可以打开“查看 → 显示 → 文件扩展名”确认。
4. 把文件拖入 PCL Lite，阅读名称和来源，点击“安装并预览”。**15 秒内点击“保留主题”**；不满意就恢复或等倒计时结束。
5. 后续在 **设置 → 个性化 → 外观主题包 → 打开主题文件夹** 中，找到已安装主题的 XAML，编辑、保存，再点击 **重新加载并预览**。

安装会复制源文件，之后改原来的下载文件不会自动更新已安装主题。要更新可以再次拖入并确认替换；日常调整推荐直接编辑主题文件夹里的已安装副本。

启动器中的 **打开注释示例** 会在 `PCL/ThemeExamples/Starter` 生成本示例与说明并打开目录；再次点击不会覆盖你编辑过的文件。这个目录是学习材料，不会自动安装或改变当前外观。

## 最先认识的几件事

| 写法 | 含义 |
| --- | --- |
| `<!-- 注释 -->` | 给人看的说明，不执行 |
| `x:Key="..."` | 资源的固定名称；通常只改对应的值 |
| `CornerRadius` | 圆角，单位 DIP；0 为直角 |
| `Padding="8,4,8,4"` | 左、上、右、下内边距 |
| `#AARRGGBB` | 颜色；AA 是透明度，00 透明、FF 不透明 |
| `{DynamicResource ...}` | 跟随当前主题/深浅色更新的资源 |
| `{TemplateBinding Content}` | 保留宿主原有内容，不要删除 |
| `PART_ContentHost` | 文本框的编辑部件，必须保留名字和类型 |

单文件示例沿用内置文字配色，可跟随深浅色模式；未声明玻璃支持，所以启用时暂停液态玻璃，原设置不变。想声明作者、兼容版本或玻璃变体时，使用 [`SoftSlate` 多文件示例](https://github.com/askbbtsk/pcl-lite/tree/main/examples/themes/SoftSlate) 和 [完整主题 API 文档](https://github.com/askbbtsk/pcl-lite/blob/main/docs/THEME-PACKS.md)。这些在线链接也能从启动器导出的本地说明中打开。

## 常见问题

- **没有变化**：确认修改的是已安装副本，并点了“重新加载并预览”；不会每次保存自动重载。
- **XAML 报错**：按提示中的文件、行列检查标签、引号和资源名；错误时保留或恢复旧主题。
- **文字太挤**：减少 Padding/字号，不要删文字、压低按钮高度或隐藏确认内容。
- **输入框不能编辑**：恢复示例里的 `ScrollViewer x:Name="PART_ContentHost"`；保留提示与校验部件。
- **版本不匹配**：阅读兼容范围后可强制预览；强制不代表跳过模板部件检查。
- **想恢复原样**：在外观主题包的主题下拉框中选择第一项“内置主题”。编辑前保留自己的副本。
