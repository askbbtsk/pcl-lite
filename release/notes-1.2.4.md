<summary>修复更新下载完成后报「SHA256 不正确」导致装不上新版本的问题。</summary>

## 更新装不上的原因

下载跑完 100% 之后，任务管理器里弹这个：

```text
System.Exception: 校验更新失败
更新文件 SHA256 不正确，应该为 ，实际为 502d5490…
```

注意「应该为」后面是**空的**。GitHub 更新源拿不到官方哈希，就把 `Sha256` 设成空字符串表示「不校验」，可下载完的校验环节是**无条件**比对的：

```csharp
var curHash = ModBase.GetFileSHA256(dlTargetPath);
if ((curHash ?? "") != (version.Sha256 ?? ""))   // "" != "502d5490…" → 必炸
    throw new Exception(...);
```

空字符串和任何真实哈希都不相等，所以这条校验**必然失败**——文件其实下得完全正确，只是被自己的校验拦下来了。1.1.0 以来所有通过 GitHub 源更新的尝试都会撞上这个。

## 改法

1. **没有官方哈希就跳过校验**，而不是拿空值去比。
2. **能拿到哈希时真的校验**：GitHub 现在会在 Release 附件上带 `digest` 字段（`sha256:…`），有就取来用。只认 `.exe` 附件——zip 的 digest 是压缩包本身的，解出来的 exe 对不上。
3. 比对改成忽略大小写，避免大小写差异造成的假失败。

## 升级路径提醒

**1.2.3 及更早的版本装不上这个更新**（bug 就在它们身上），需要手动下载一次本版安装包，之后自动更新就正常了。

## 校验

```text
SHA-256: b6ef46bdffbbaba227108d042840ab8dbc4f87babda0e352ce1ce0b8185cfd82
```
