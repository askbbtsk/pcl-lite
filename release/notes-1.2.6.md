PCL Lite 1.2.6-beta。

## 本次内容

### 新增：基岩版成为独立板块

顶部导航多了一个 **基岩版**，就在「下载」右边，与启动、下载平级。板块内分 **下载** 与 **启动** 两页，
和 Java 版一样「在启动器里下载、在启动器里启动」，不再只是「找到已装的版本然后启动」。

#### 下载

- 版本列表来自 `data.mcappx.com`，微软商店已发布的基岩版全在里面：正式版 / 预览版 / Beta，
  共 500 多条，按版本号从新到旧排
- 支持按 **发布通道**、**包形态**（UWP / GDK）筛选，也可以直接搜版本号
- 点右侧按钮即 **下载 + 安装** 一条龙，进度条与百分比实时显示，下载完自动校验官方 MD5
- **UWP（商店包）**：解压 → 删签名 → 改写清单（版本号 / TrustLevel / runFullTrust）→
  `Add-AppxPackage -Register` 注册进系统。可以装商店里已经没有的旧版本，多版本并存，
  商店更新也不会把它顶掉。需要开发者模式（旁加载），没开的话点「开发者模式」按钮可以一键尝试开启
- **GDK 包**：`.msixvc` 是加密的 XVC 容器，用内容密钥（CIK）解密后解包到启动器自己的目录，
  之后直接跑 `Minecraft.Windows.exe`，不注册系统包，多版本天然共存、甚至可以同时开
- 下载的包、解包出来的版本都在启动器数据目录的 `Bedrock/` 下，删启动器时一起走

#### 启动

- 列出本机所有可启动的基岩版：商店里装的正式版与预览版、下载页解包出来的版本、
  以及你手动添加的 GDK 目录（一级子目录也会扫）
- 启动、结束进程、打开程序目录、打开存档目录，都不需要管理员权限
- 商店版走 `shell:appsFolder\<包家族名>!<AppId>`，GDK 版直接起主程序

## 关于 GDK 包的内容密钥

GDK 包的 CIK 是微软商店的分发凭据，**不写进源码**，编译时通过环境变量注入：

```powershell
$env:PCL_BEDROCK_RELEASE_CIK = "<正式版 CIK>"
$env:PCL_BEDROCK_PREVIEW_CIK = "<预览版 CIK>"
```

本发布包未包含 CIK，所以 GDK 版本可以正常列出、正常下载，点安装时会明确提示
「当前构建未包含基岩版 GDK 内容密钥（CIK），无法解包这个安装包」。
**UWP（商店包）的下载与安装不受影响。**

## 已知问题

- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
- GDK 解包需要 CIK，本发布包未内置（见上）
- 下载源为社区维护的商店版本索引，接口变动时列表可能拉不到，界面会给出明确提示
- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- 自动更新暂不做完整性哈希校验，以下载通道自身的安全性为准
