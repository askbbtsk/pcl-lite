## QQ 交流群改用官方短链

1.3.1 里点「QQ 交流群：1085542362」走的是 `mqqapi://card/show_pslcard` 协议。
实际用下来问题不少：

- 只弹**群名片**，还得用户自己再点一次「申请加群」，不是一步到位
- 没装 QQ、或系统把协议关联清理过（部分精简系统、第三方管家会清）的机器上，
  点下去没有任何反应
- 部分浏览器/系统组合会拦截未知协议，弹一个「无法打开」的对话框

现在改成 QQ 官方后台生成的加群短链：

```
https://qm.qq.com/q/BmreYx71rq
```

点一下就是**用默认浏览器打开**，短链 302 跳到 `qun.qq.com` 的群分享页，
手机上会直接唤起 QQ 并落在加群界面，桌面上则在浏览器里展示群信息与「加入群聊」按钮。
不依赖本机协议注册，没装 QQ 也能看到群信息。

浏览器都起不来（极少见，通常是默认浏览器关联被破坏）时，仍然退化为
「复制群号 + 提示」，保证点一下总有结果。

入口位置不变：**欢迎页的「社区」卡片**，以及 **设置 → 关于 → 贡献者列表下方**。

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- 自动更新暂不做完整性哈希校验，以下载通道自身的安全性为准
- 主页语言信封与 `lang:` 标签是 PCL Lite 扩展，原版 PCL 加载含这些内容的文件时
  会按普通 XAML 渲染（所有语言分支堆在一起）——属于预期的单向兼容
- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
