## Lunar Client 支持（新增，实验特性）

导航栏「基岩版」右侧多了 **Lunar**。它不是下载器，前提是本机已经装过 Lunar Client
并至少启动过一次，让物料与 JRE 落盘。PCL 只做一件事：**绕过 Lunar 启动器，直接拉起游戏进程**。

- **物料实时获取**：向 Lunar 服务端要清单，按 SHA-1 增量补齐。已存在的文件直接跳过，
  不会重复下载几万个资源
- **正版验证走原通道**：用你在 PCL 登录的微软账号拿到的 accessToken，
  与 Lunar 启动器传给游戏的完全是同一个东西，不经过任何第三方中转
- **不碰 Lunar 本体**：不改它的安装目录，不动它的配置，随时可以退回官方启动器
- 支持 1.8.9；JRE 自动按服务端给的位置定位，不用自己挑 Java

启动页会实时显示状态、物料目录、用到的 Java，并把游戏输出打到日志里。
「复制启动命令」会先把 accessToken 打码再复制，方便排查问题又不至于泄露账号。

### 当前不支持

- **好友与社交面板不可用**：Lunar 的本地 IPC 服务没有实现，游戏侧每 5 秒会重试一次并打日志。
  单人、多人、模组、OptiFine 都正常
- 只有 1.8.9，其他版本还没接

## 功能隐藏：可以关掉基岩版和 Lunar

「设置 → 界面 → 功能隐藏」的「主页面」那行，新增 **基岩版** 与 **Lunar** 两个开关。
不玩这两个板块的话勾上，顶部导航栏就不显示。和原有的下载/设置/工具一样，
按 F12 可以临时全部显示。

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- Lunar 的本地 IPC 服务未实现，好友与社交面板不可用（见上文）
- 基岩版 GDK 安装包（`.msixvc`）解包依赖内置的内容密钥（CIK），正式版与预览版各一把，
  均已编入本构建；密钥若被官方轮换会失效，届时用环境变量覆盖即可，不必重新下载启动器
- 主页语言信封与 `lang:` 标签是 PCL Lite 扩展，原版 PCL 加载含这些内容的文件时
  会按普通 XAML 渲染（所有语言分支堆在一起）——属于预期的单向兼容
- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
