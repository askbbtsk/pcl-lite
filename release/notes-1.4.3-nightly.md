PCL Lite 1.4.3 不稳定版（nightly）。

## 这个版本修两件事、加一个开关

### 1. 游戏内 Lunar 菜单不显示

Lunar 把界面资源按 SHA-1 分目录放在 `~/.lunarclient/ui/<sha1>/` 下，里面才是
`index.html` 和 `static/`。之前 `--uiDir` 只指到了 `ui/` 那一层，Genesis 找不到
`index.html`，于是游戏内菜单整块不显示——但 HUD、模组、游戏本体都正常，很容易
误以为是别的问题。

1.4.3 按服务端返回的 `ui.sourceSha1` 拼到正确那一层。本地没有这份资源的话会
自动下载并解压。

### 2. 物料校验改成多线程

61 个附件里有几个几十 MB 的 jar，串行算 SHA-1 要好几秒，而且时间基本都耗在等磁盘上。
现在按 CPU 核数并发（封顶 8 路），慢盘上差别最明显。

### 3. 新增开关：启动 Lunar 前校验物料文件

**设置 → 启动 → 高级**，最下面一项。

- **勾着**（默认）：每个文件都算 SHA-1，对不上就重新下载。最稳
- **不勾**：只判断文件在不在，不算哈希。省掉大文件的哈希计算，启动更快；
  代价是文件损坏了发现不了，得手动删掉那个文件让它重下

## 1.4.2-nightly 带来的改动（没变）

### 正版登录：改用 PCL CE 的 Client ID

之前用的是 PCL Lite 自己申请的 OAuth 应用，**那个应用没过审，登录会 403**。
现在换成 PCL CE 的（已验过 `login.microsoftonline.com` 的 devicecode 接口返回 200）。

### Lunar 启动复用主页面凭据

不再重复弹登录。只有主页面还没登录过时才兜底走一次。

### Lunar Client 支持（实验特性）

导航栏「基岩版」右侧的 **Lunar**。前提是本机已装过 Lunar Client 并至少启动过一次。
PCL 只做一件事：**绕过 Lunar 启动器，直接拉起游戏进程**。

- **物料实时获取**：向 Lunar 服务端要清单，按 SHA-1 增量补齐
- **正版验证走原通道**：用你在 PCL 登录的微软账号拿到的 accessToken
- **不碰 Lunar 本体**：不改它的安装目录，不动它的配置
- 支持 1.8.9；JRE 自动按服务端给的位置定位

### 功能隐藏：可以关掉基岩版和 Lunar

「设置 → 界面 → 功能隐藏」的「主页面」那行，新增 **基岩版** 与 **Lunar** 两个开关。
按 F12 可以临时全部显示。

### 当前不支持

- **好友与社交面板不可用**：Lunar 的本地 IPC 服务没有实现，游戏侧每 5 秒会重试一次并打日志。
  单人、多人、模组、OptiFine 都正常
- 只有 1.8.9，其他版本还没接

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- Lunar 的本地 IPC 服务未实现，好友与社交面板不可用（见上文）
- 基岩版 GDK 安装包（`.msixvc`）解包依赖内置的内容密钥（CIK），正式版与预览版各一把，
  均已编入本构建；密钥若被官方轮换会失效，届时用环境变量覆盖即可，不必重新下载启动器
- 主页语言信封与 `lang:` 标签是 PCL Lite 扩展，原版 PCL 加载含这些内容的文件时
  会按普通 XAML 渲染（所有语言分支堆在一起）——属于预期的单向兼容
- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
