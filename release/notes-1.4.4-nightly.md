PCL Lite 1.4.4 不稳定版（nightly）。

> **这是 nightly，不是正式版。** 只有把更新通道选成「最新」才会收到。

## 这个版本改四件事

### 1. Lunar 支持全部版本

之前写死 1.8.9。现在从服务端拉完整版本列表，**34 个子版本全都能选**：

| 大版本 | 子版本 |
| --- | --- |
| 26 | 26.1、26.1.1、26.1.2、26.2、26.3 |
| 1.21 | 1.21 ～ 1.21.11（11 个） |
| 1.20 | 1.20 ～ 1.20.6（7 个） |
| 1.19 | 1.19、1.19.2、1.19.3、1.19.4 |
| 1.18 / 1.17 / 1.16 / 1.12 / 1.8 / 1.7 | 1.18.2、1.18.1、1.17.1、1.16.5、1.12.2、1.8.9、1.7.10 |

高版本的启动方式**没有换**——主类还是 Genesis，参数一个没变。真正变的是三样：

- **JRE**：1.8.9～1.20.1 用 Java 17，1.20.6～1.21.11 用 Java 21，26.x 用 Java 25。
  本机缺哪份就按服务端地址自动下（Zulu 官方包，带备用 CDN）
- **`jre.extraArguments`**：官方启动器按版本下发的 JVM 参数，现在原样带上。
  1.21+ 少了会在启动早期直接报模块访问错误，26.x 还多 ZGC 那几条
- **物料版本**：`offline/multiver` 是所有版本共用的目录，文件名固定、换版本会被覆盖。
  文件在但版本不对时启动会抛 `NoSuchMethodError`，所以**跨版本切换时别关掉物料校验**

实测：1.8.9、1.21.4、26.3 三个跨度最大的版本都用假 token 真拉起来过，
Mixin 加载、类 bake、`Starting game!` 全部正常。

### 2. 账号：改用 Lunar 自己的账户库，并且能选了

这是之前一直没说清的一件事。**Lunar 游戏进程不认命令行里的 accessToken**——
它读的是 `~/.lunarclient/settings/game/accounts.json` 里的激活账号，
token 过期还会自己刷新。所以在 PCL 里换了账号、进游戏还是原来那个，不是登录没生效，
而是 Lunar 根本没看我们传的凭据。

现在：

- Lunar 板块里多了一个**账号下拉框**，列出 Lunar 账户库里的全部账号
- 选完在启动时把 Lunar 的激活账号同步过去（等同于在 Lunar 启动器里换号），
  改之前会备份一份 `accounts.json.pclbak`，只改 `activeAccountLocalId` 一个字段
- Lunar 账户库为空时，才回落到 PCL 主页面的登录凭据
- 因此**启动 Lunar 不再要求 PCL 先登录正版**，只要 Lunar 里有账号就行

### 3. 启动目录不再和普通版本混淆

之前 Lunar 的 `--gameDir` 写死成 `.minecraft` 根目录，而正常启动用的是实例的
版本隔离目录。结果是「主页面选的是实例 A，Lunar 却把存档写进根目录」，
两边的 `saves`、`options.txt`、`mods` 混在一起。

现在 Lunar 和正常启动用同一个目录（当前选中实例的版本隔离目录），
界面上也直接显示这次会写进哪个目录，不用猜。

### 4. 运行中，左下角按钮变成「强制停止」

游戏跑起来之后，Lunar 板块左下角那颗按钮原地变成红色的「强制停止」，
点一下连同子进程一起结束。右栏那颗按钮行为一致。

## 从 1.4.3-nightly 升上来

直接覆盖，配置不变。默认版本仍是 1.8.9，账号默认跟随 Lunar 当前的激活账号，
行为和之前一致；想换版本/换账号在 Lunar 板块里选即可。

## 当前不支持

- **好友与社交面板不可用**：Lunar 的本地 IPC 服务没有实现，游戏侧每 5 秒会重试一次并打日志。
  单人、多人、模组、OptiFine 都正常
- **`baseModpack`**（1.21+ 响应里那份 mrpack）没有铺进实例。官方启动器用它铺
  Fabric 侧的模组，目前实测不铺也能起来；如果某些模组功能异常，先怀疑这里

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- Lunar 的本地 IPC 服务未实现，好友与社交面板不可用（见上文）
- 首次切到一个没玩过的 Lunar 版本时，需要下载该版本全部物料（几十到一百多 MB）
  和对应 JRE（约 40 MB），会慢一次
- 基岩版 GDK 安装包（`.msixvc`）解包依赖内置的内容密钥（CIK），正式版与预览版各一把，
  均已编入本构建；密钥若被官方轮换会失效，届时用环境变量覆盖即可，不必重新下载启动器
- 主页语言信封与 `lang:` 标签是 PCL Lite 扩展，原版 PCL 加载含这些内容的文件时
  会按普通 XAML 渲染（所有语言分支堆在一起）——属于预期的单向兼容
- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
