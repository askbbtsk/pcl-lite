PCL Lite 1.5.11 预览版（pre）。

> **这是预览版，不是正式版。** 把更新通道选成「预览体验」就能收到；
> 「快照尝鲜」「始终最新」也会收到，「稳定版」不会。

## 一、远程收集版本号，删掉了

「设置 → 关于」里原本写着：

> 本软件的 User Agent 中包含启动器的版本号，以统计各版本的用户数量。

这句话不是免责声明，它描述的是一件真事：每个出站请求都自带构建号。落在对方的日志里，
就是一张「谁在用哪个版本、多少人在用」的统计表 —— 不需要任何额外的埋点。

这次把三处上报点全部掐掉：

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| `HttpSenderExtension`（通用请求） | `PCL-Lite/1.5.10-pre` | `PCL-Lite` |
| `NetworkService`（HttpClient 默认头） | `PCL-Lite/1.5.10-pre` | `PCL-Lite` |
| `RequestSigning`（下载器的 UA） | `PCL2/2.12.1.0 PCLCE/1.5.10` | `PCL2 PCLCE` |

顺带删掉一处更隐蔽的：通用请求原来还带

```
Referer: https://<构建号>.ce.open.pcl2.server/
```

构建号直接写进了域名。这一行整个去掉了 —— 它本来只是为了对齐上游的鉴权口径，
而 PCL Lite 的请求根本不需要它。

需要伪装成浏览器时（个别 CDN 会拦非浏览器 UA），浏览器段原样保留，
只是前面不再挂版本号：

```
PCL2 PCLCE Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... Edg/136.0.0.0
```

**除此之外，网络行为一个字都没动**：没有新增请求，没有新增字段，也没有关掉任何已有功能。
更新检查、下载、登录、联机全部照旧。

## 二、「关于」页删了两块东西

**那段说明**。「User Agent 中包含版本号以统计用户数量」已经变成假话，留在「关于」页只会误导人，
所以整段（含「隐私说明」小标题）一起删掉了。

**「用户协议与免责声明」按钮**。它指向一份放在外部的石墨文档，和本仓库的 `LICENSE`、
`docs/CREDITS.md` 不是同一份东西，链接也早就没人维护了。留着只会让人点进去看一份过期条款，
所以去掉；「开源与法律信息」卡片里仍然保留 README 和「查看开源代码」两个入口。

「关于」页的「其他信息 / 版权」部分和其余卡片不变。

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- 基岩版 GDK 安装包（`.msixvc`）解包依赖内置的内容密钥（CIK），正式版与预览版各一把，
  均已编入本构建；密钥若被官方轮换会失效，届时用环境变量覆盖即可，不必重新下载启动器
- PCL2 原版（`setup.ini`）来源的导入只搬设置，**账号需要在账号页重新登录**——
  那一代的账号不是按新格式存的，硬转会写坏账号库
- PCL2 原版里改过名的键搬不过来，比如「上次选的版本」（PCL Lite 叫 `LaunchInstanceSelect`，
  PCL2 叫 `LaunchVersionSelect`），导入后需要重新选一次
- Lunar 的本地 IPC 只实现了 `AuthService/RefreshAccount`（会话续期），
  好友列表、游戏内商店、聊天面板这些走 IPC 的功能仍然是空的。回空响应是安全的，
  游戏不会崩，只是对应界面没数据。
- Lunar 物料清单接口偶发 `SSL unexpected EOF`，重试几次通常能过
- 补齐原版依赖这一步是按文件存在性判断的，不校验哈希；文件损坏（下了一半）仍要等
  Genesis 自己发现并重下，那种情况依旧没有进度
