PCL Lite 1.5.2 快照版（snapshot）。

## ① 不用再装 Lunar 启动器了

以前 PCL 启动 Lunar 有个隐含前提：**本机已经装过 Lunar 官方启动器**。
物料缺了只会甩一句「请先用 Lunar 启动器跑一次这个版本」，全新机器直接卡死。

现在官方启动器准备物料的那 7 个阶段，全部由 PCL 自己跑，顺序也照抄：

```
licenses → textures → assets → artifacts(+natives) → jre → ui → logs
```

| 阶段 | 以前 | 现在 |
| --- | --- | --- |
| 许可文件 | 没做 | 补齐 48 份 |
| 外观资源（皮肤/披风/表情） | 没做 | 索引式下载 465 项 |
| 原版资源 objects | **只补索引，不拉文件** | 722 个对象全补齐 |
| 客户端 jar + 原生库 | 有 | 有，且单文件失败不再拖垮整段 |
| Java 运行时 | 有 | 有 |
| 界面资源 | 只解 source.zip | 再跑一遍索引，补齐运行时资源 |
| 日志配置 `config.xml` | 没做 | 自动生成 |

`~/.lunarclient` 是空的也能一路装完。实测全新目录装 1.8.9：
**478 MB / 约 4 分 45 秒**；第二次启动 **6 秒**（文件都在，全部命中哈希，几乎零流量）。

装过 Lunar 启动器的机器不受影响 —— 目录结构完全一致，PCL 直接复用已有的文件。

## ② 原版资源走镜像，跟着设置走

原版 `objects` 和资源索引（`launchermeta`）不再直连 Mojang，改走
**「设置 → 下载 → 文件下载源」** 同一份实现：

- 优先镜像 → BMCLAPI 在前，官方兜底
- 自动 → 看官方源探测耗时决定先后
- 优先官方 → 官方在前，镜像兜底

顺带把 `ModDownload` 里那套镜像逻辑下沉成了唯一实现（`PCL.Core/IO/Net/DownloadSource.cs`），
以后改镜像域名只需要改一处。

Lunar 自己的 CDN（客户端 jar、textures、ui、licenses、jre）没有镜像，只能直连。

## ③ 下载不再一碰就碎

- **单文件重试 3 次**（退避 300ms / 1200ms）。实测 Lunar 的物料 CDN 偶发
  `SSL unexpected EOF`，以前一个文件抖动就让整段物料下载失败。
- **失败聚合**：几百个文件并发拉，先把所有能下的都试完，最后一次性告诉你哪几个没下来，
  已下好的不会重下。不会因为一个文件就白等一遍。
- 并发度从「按核数」提到「核数 × 2（4～16）」—— Lunar 物料是几百个小文件，
  瓶颈在往返延迟而不是带宽，这一项让首次安装快了一倍多。

## ④ 新增「设置 → Lunar」页

以前 Lunar 的内存、JVM 参数是写死的，改不了。现在可以配：

- **最大内存**：默认跟随 PCL 的全局内存设置，也可以单独指定
- **附加 JVM 参数**：例如 `-XX:+UseG1GC -XX:+AlwaysPreTouch`
- **Java 路径**：留空就用 Lunar 自带的 JRE；指定了就直接用你的

而且**支持为每个版本单独设置**：想给 26.3 分 8 GB、给 1.8.9 分 2 GB，可以各配各的，
没单独配的版本自动沿用全局。

用户写的参数排在**所有官方参数之后** —— JVM 对重复参数取最后一次，
这样你写的 `-Xmx`、`-XX:+UseZGC` 才能盖掉官方下发的默认值。

## ⑤ 几个不显眼但会咬人的修复

- **日志配置写错**：`config.xml` 里滚动日志的文件名会变成 `gz-<路径>\latest.log`。
  原因是 C# 的 `string.Replace` 替换**全部**出现位置，而官方启动器用的 JS
  `String.replace` 只替第一个 —— 短的占位符把长的那个也吃了。
- **`installation-id` 每次启动都换**：以前只读不写，服务端会把同一台机器当成无数次全新安装。
  现在生成后落盘复用。
- **账户库不存在时没有身份**：游戏进程只认 `accounts.json` 里的激活账号，
  全新机器上这个文件根本不存在。现在缺失时按这次登录自动创建一份；
  **已有账号一律不动**。

## 已知问题

- 发布文件已做代码签名（SHA-256 + DigiCert 时间戳）；证书为自签名，暂无商业信誉，
  个别安全软件首次运行时仍可能提示发布者信息
- 基岩版 GDK 安装包（`.msixvc`）解包依赖内置的内容密钥（CIK），正式版与预览版各一把，
  均已编入本构建；密钥若被官方轮换会失效，届时用环境变量覆盖即可，不必重新下载启动器
- Lunar 的本地 IPC 只实现了 `AuthService/RefreshAccount`（会话续期），
  好友列表、游戏内商店、聊天面板这些走 IPC 的功能仍然是空的。回空响应是安全的，
  游戏不会崩，只是对应界面没数据。
- 首次安装会下 300～500 MB（取决于版本），网速慢的话请耐心等进度条。
- 主页语言信封与 `lang:` 标签是 PCL Lite 扩展，原版 PCL 加载含这些内容的文件时
  会按普通 XAML 渲染（所有语言分支堆在一起）——属于预期的单向兼容
- UWP 安装需要开发者模式；系统策略禁用旁加载时只能手动到「设置 → 系统 → 开发者选项」打开
