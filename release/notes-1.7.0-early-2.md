> 抢先体验版：1.7.0 正式发布之前先放出来的那一份。四个更新通道（稳定版 / 预览版 / 快照版 / 始终最新）都能收到它。

## 改了什么

### 用户文件夹名打码（默认开）

界面和启动日志里到处是 `C:\Users\xxx\AppData\...` 这种路径，随手截个图就把 Windows 用户名带出去了。这一版把 **`Users` 后面那一段**统一显示成 `*****`：

```
改前：C:\Users\18857\AppData\Roaming\.minecraft
改后：C:\Users\*****\AppData\Roaming\.minecraft
```

几个细节：

- **按路径结构打码，不是整串替换**。只换 `Users` 路径段紧跟的那一段，其余字符一个不动 —— 用户名恰好是纯数字时，日志里的版本号、文件大小不会被牵连
- **所有用户文件夹都打**：别人的账号、`C:\Users\Public`、正斜杠写法 `C:/Users/...` 一并处理
- **固定五个星号**，不按名字长度补 —— 星号个数等于名字长度，本身就是一条信息
- **崩溃报告始终打码**，不受下面那个开关影响（那是要发给别人看的）

### 有问题就关掉

打码会影响显示，如果你需要看真实路径排查问题，或者觉得哪里打过头了：

**设置 → 个性化 → 基础 → 取消勾选「界面上的用户文件夹名打码」**

立刻生效，不用重启。只影响显示，不会改动磁盘上任何文件夹或文件。

## 已知问题

- **Cookie 登录仍然没有在「真实且未过期的会话」下跑通过一次**。格式识别（含浏览器扩展导出的 cookies.txt）已经补齐，但手上那份导出里的 `MSPAuth` / `MSPProf` 都是 `Disabled`（登出状态留下的），验证不到最后一步
- 令牌导入的账号 24 小时后必须重新导入，这是微软定的，没有绕法
- 之前被误标成「设备代码」的旧档案，数据上已经还原不出原始登录方式了，需要删掉后用同一个 Refresh Token 重新导入一次
