## 修了什么

`1.7.0-early-2` 的用户文件夹名打码漏了两处，因为这两处的路径是**直接赋给控件的**，没走本地化文本那条路：

- **实例选择左栏**：每个文件夹下面那行路径（`C:\Users\xxx\AppData\Roaming\.minecraft` 之类）还是真名
- **设置 → Java**：每个 Java 的副标题（安装目录）还是真名

现在两处都打码了，效果和别的地方一致：

```
改前：C:\Users\18857\AppData\Roaming\.minecraft
改后：C:\Users\*****\AppData\Roaming\.minecraft
```

其余行为不变：默认开着，固定五个星号，只换 `Users` 后面那一段，崩溃报告始终打码。

### 有问题就关掉

**设置 → 个性化 → 基础 → 取消勾选「界面上的用户文件夹名打码」**，立刻生效，不用重启。

## 已知问题

- **Cookie 登录仍然没有在「真实且未过期的会话」下跑通过一次**。格式识别（含浏览器扩展导出的 cookies.txt）已经补齐，但手上那份导出里的 `MSPAuth` / `MSPProf` 都是 `Disabled`（登出状态留下的），验证不到最后一步
- 令牌导入的账号 24 小时后必须重新导入，这是微软定的，没有绕法
- 之前被误标成「设备代码」的旧档案，数据上已经还原不出原始登录方式了，需要删掉后用同一个 Refresh Token 重新导入一次
