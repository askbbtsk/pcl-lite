# PCL Lite 1.7.1 hotfix 4

本版本将构建告警清零，并修复安全审计中确认的问题：

- 移除提权服务中通过 `start` / `start-json` 任意启动进程的路径，避免以管理员权限执行不受信任的 `ProcessStartInfo`。
- 收紧外部链接和 shell 调用的输入校验，避免把不受信任链接交给系统 shell。
- 修复调试 MCP 服务的路径校验绕过，并保持服务默认拒绝写入、游戏控制和启动器配置权限。
- 更新包下载后验证 Sigstore 证书；验证失败时显示红色警告，并默认建议“不更新”。
- 发布构建只注入 OAuth Client ID 和提交标识，不把 API Key 或其他服务器凭据写进客户端。

基岩版 CIK 解密逻辑保持不变。

验证结果：Debug、CI、Beta、Release 构建均为 0 警告、0 错误；572 个 .NET 测试和 4 个 MCP 路径测试通过。
