# PCL Lite 1.7.2 热修复 2

本次热修复补齐插件 API 与 PCL 主页的实例管理行为，并修正 Lunar 社交页连接体验和更新签名文件的下载回退。

## 插件系统

- 插件 Minecraft 实例查询改为复用 PCL 当前 Minecraft 文件夹和原生实例列表扫描器。主页先恢复已选实例、实例列表尚未扫描完成时，插件不再误报 0 个实例。
- 插件按 PCL 原生启动入口启动实例；启动选项仍由原生启动流程处理。实例路径只会映射到 PCL 已识别的实例对象，不接受任意路径创建实例。
- 插件市场卡片的“打开官网”按钮移至卡片右下角，避免与安装状态和操作按钮重叠。

## Lunar 与更新

- 打开 Lunar 页面后自动连接好友与私聊后端；连接前等待现有令牌预热完成，避免令牌刷新竞争。连接失败时显示错误提示。
- 更新 EXE 的 Sigstore sidecar 文件也加入配置的 GitHub 镜像回退。镜像只负责传输；安装更新前仍由启动器验证 Sigstore 签名身份。

## 验证

- `PCL.Core.Test` 全部测试通过。
- 启动器 Debug 构建通过，0 警告、0 错误。
