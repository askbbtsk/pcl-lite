# PCL Lite 1.7.2

本版本汇总 PCL Lite 1.7.1 正式版以来的全部更新，包含 1.7.1 热修复 1–4，以及插件系统和 SDK。

## 插件系统与市场

- 新增插件市场与已安装插件页面，插件市场入口位于基岩版旁；支持从市场和本地 `.pclplugin` 文件安装、更新、启用、禁用和卸载。相关操作会提示重启后生效。
- 插件包支持自签名证书。安装和加载时都会校验签名及包内文件哈希；签名人、证书指纹、签名声明时间、安装来源、包 SHA-256 和可验证的 GitHub Release 信息会展示给用户。签名无效或内容被篡改时拒绝安装；未签名包需要用户明确确认。
- 自签名只能证明包内容与签名匹配，不证明作者身份，也不提供沙箱隔离。插件与启动器在同一进程、使用相同用户权限。
- 插件按依赖顺序加载，互相复用已加载依赖，并可声明 PCL Core 兼容范围。单个插件启动失败会被隔离记录；安装、更新、启用、禁用和卸载需要重启启动器生效。
- 插件可选择启用默认关闭的实验 Mixin 功能；相关操作和加载错误会记录，并提供回退开关。
- 插件市场索引验证 HTTPS、GitHub Release 资产地址与 SHA-256；来源或包内容变化会向用户说明。

## SDK 与开发工具

- 扩展版本化插件 API，涵盖生命周期、日志、独立存储和设置、PCL 主题按钮、通知和选择对话框、插件页面显示/隐藏生命周期、动态注销页面、事件、HTTP 请求、带 SHA-256 校验的下载、启动器信息、Minecraft 实例查询/配置/启动选项，以及进程内服务注册与获取。
- 存储 API 增加字节、流、存在性、列出和删除操作；网络 API 增加请求头与超时；响应支持原始二进制数据。
- 提供插件示例、全 API TestAll 烟测插件、SDK 文档，以及证书生成、签名打包工具。

## 安全、更新和稳定性

- 1.7.1 热修复 4：移除提权服务中可通过 `start` / `start-json` 任意启动程序的路径；收紧 shell 和外部链接调用；修复调试 MCP 服务路径校验绕过。
- 更新下载增加 Sigstore 证书验证；验证失败时显示警告，默认建议不更新。正式发布工作流要求从 `main` 触发，并为 x64 和 ARM64 资产附加 GitHub OIDC/Sigstore 签名。
- 发布构建只注入 OAuth Client ID 和提交标识；不把 OAuth Client Secret、API Key 或其他服务端凭据写进客户端。
- 修复 Lunar 首次启动门禁和 UI 目录误判；打开 Lunar 页面时预热会话令牌。
- 修复服务器地址探测取消处理及旧框架兼容性问题。
- 清理 en-GB 语言资源，统一显示为 English；原有 en-GB 配置会自动映射到 en-US。
- Bedrock/CIK 解密逻辑保持不变。
