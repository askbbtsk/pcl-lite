# PCL Lite 1.7.5-early-1

本次预览版包含 pre-4 的全部功能，并合入 PR #8 的原生液态玻璃及维护者复审修复。

## LiquidGlass Core

- 替换旧的未接线液态玻璃资源，主实现统一命名为 `LiquidGlassCore`，源码和资源文件采用 LiquidGlass 命名。保留原 PR 的控件及配置兼容入口、作者提交和第三方来源声明。
- 设置 → 个性化新增独立液态玻璃卡片，默认关闭，不属于高级材质。启用时弹出性能确认，无倒计时；取消不会开启，确认后在开关下展开配置。
- 提供低消耗、均衡、高画质、极致四档，实际调整模糊、色散、高光、按压动效和默认帧率；原生预设框及选项最小高度 38 DIP，开关高 32 DIP。
- 原生滑块可独立选择 30–240 FPS，最右端不限制。上限用于桌面回读/上传和玻璃按压动画，移动窗口不绕过限制；不修改 Minecraft 帧率，也不保证效果实际达到该帧率。
- 各档开销为相对预估，硬件、分辨率、多屏和背景影响实际负载，不虚构 CPU 百分比或固定内存成本。

## 截图及恢复

- 默认使用启动器背景作为折射源，可正常截图，不会设置系统截图排除。没有配置背景或不支持着色器时使用静态/兼容材质。
- 原 PR 的实时桌面模式为避免递归采集，会通过 Windows 将启动器从截图和录屏中排除，这就是“截图时窗口消失”的原因，实际窗口并未关闭。
- 实时桌面改为默认关闭，另行开启前再次明确确认采集开销及截图限制；关闭该选项恢复截图可见性。旧实验配置没有新确认标记时不能静默开启。
- 修复多屏恢复重试耗尽后健康会话仍残留、旧帧无效但窗口仍排除截图的问题：最终失败时退役全部采集并恢复截图状态。
- 截图状态恢复暂时失败时，独立执行最多三次延迟重试；采集停用或 Dispose 后仍保留有限恢复，窗口销毁时停止，永久失败记录日志。

## 验证与发布

- GitHub CI 验证核心测试、原 PR 的玻璃几何/材质/采集测试、新增帧率边界及恢复故障测试、TestAll、源码契约以及 x64 / ARM64 构建。
- 发布流程注入 OAuth client ID，并为两种架构分别生成和验证 Sigstore 签名。
- 真实桌面采集、多显示器拔插和各 DPI 的视觉矩阵仍需实机验收；CI 替身测试不等于所有 GPU、截图软件都已验证。

## 建议测试

1. 开启液态玻璃，取消性能确认应保持关闭；确认后设置展开，默认背景模式可截图。
2. 切换四档预设并拖动帧率滑块，检查 30、60、240 FPS 和不限制的显示与实时效果。
3. 明确开启实时桌面模式，检查截图限制提示；关闭后确认截图恢复。
4. 测试最小化、隐藏恢复、连续开关、修改壁纸及主题，确认设置保存并恢复正常。
