# PCL Lite 1.7.5 hotfix-1

本次修复基于 1.7.5 正式版。

- **减小程序体积**：LiquidGlass 改用构建时按需生成的 Windows 接口，不再携带完整的 Windows SDK .NET 适配程序集或独立的 WinRT.Runtime。桌面捕获和 D3D11 继续使用 Windows 自带组件，无需首次启动下载额外玻璃依赖。
- **精简图形封装**：D3D11 改为仅保留捕获流程所需的 COM/PInvoke 调用，移除整套 Vortice/SharpGen 封装。发布流水线检查 x64、ARM64 程序均不超过 30 MB；保留现有功能及发布方式，不通过删除功能、捆绑运行时或启用 WPF 全程序裁剪减小体积。
- **修复液态玻璃的背景不透明度**：此前背景层变淡后，父容器仍绘制一份不透明底色，导致背景看起来没有变化。现在主题底色只绘制一次；开启液态玻璃时，滑块仅调整主题背景和图片、视频背景。
- **保留前景清晰度**：调整背景不透明度时，玻璃、实时桌面采样、文字和 PCL Lite 徽标保持原有不透明度。关闭液态玻璃后恢复原有整窗不透明度行为。
- **验证**：新增实际窗口 XAML 的背景分层和像素混合回归、WinRT 设备封送及帧池事件测试，并执行完整单元测试和 x64 / ARM64 构建。完整显示器、显卡和 DPI 视觉矩阵仍需用户实机验证。
