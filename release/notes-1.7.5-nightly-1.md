# PCL Lite 1.7.5-nightly-1

本次为预览版本，供 LF 功能移植阶段验收。

## 新增与改进

- 支持从本地 ZIP / MRPACK 整合包更新已有实例，复用暂存安装、文件差异预览及保留个人修改流程。实例需有已记录的安装基线；Minecraft 版本及加载器类型需匹配。
- 支持基于 CurseForge / Modrinth 来源选择整合包版本并更新；新增、修改、移除和玩家文件冲突在更新前预览。
- 更新前保留原始文件并写入事务记录；中断后在再次启动游戏或更新前恢复原文件，移除已识别的未完成新文件，不继续执行中断的更新。遇到外部修改时保留恢复数据并停止自动处理。
- 本地模组、资源包、光影和原理图增加启动器内部回收站，支持恢复和彻底删除；资源更新替换的旧文件也可找回。
- 新增世界手动/自动备份、独立保留策略、实例环境还原点及已删除备份恢复；恢复环境不回退存档进度。
- 加入测试副本、最近世界记录与继续游玩、按类别同步个人游戏设置，以及崩溃后环境变化对照与恢复入口。
- 启动前检查模组必需依赖，可启用匹配的禁用前置并确认补齐；导出启动脚本时跳过依赖处理。
- 整合包附带启动器时使用 PCL Lite 包体。
- 同步主页性能卡改进与本地化，保留现有插件、Bedrock、CIK 和 Lunar 入口。

## 验收说明

- LF 对照参考为提交 `09ce7a5`；尚未完成 LF 与 Lite 使用真实整合包双跑后的逐文件字节一致性验收。
- 本地包的作者身份无法通过文件选择确认；选择前会提示，沿用已有项目关联需要用户确认包的来源。
- 本版本以 GitHub Actions 发布构建，注入 OAuth client ID，并随附 Sigstore 验签文件。
