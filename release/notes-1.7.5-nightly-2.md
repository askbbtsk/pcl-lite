# PCL Lite 1.7.5-nightly-2

本次为预览版本，包含 nightly-1 的功能，并调整备份和文件删除体验。

## 修复与调整

- 修复展开世界备份卡片时报找不到 `Images/Blocks/Chest.png`，导致备份列表及还原按钮无法加载的问题，改用现有图标。
- 移除启动器内部资源回收站、已删除备份和还原点的恢复入口。
- 新增“设置 → 杂项 → 文件删除 → 删除时移入 Windows 回收站”，默认开启；关闭后直接删除。资源、数据包、截图、存档和实例删除采用该设置，资源更新替换的旧文件同样适用。
- 实例还原点删除后不可找回。
- 移除启动前、退出后、整合包更新前及恢复前自动创建备份/还原点的逻辑；保留手动备份和手动还原点。已有备份文件保留。
- 历史自动备份记录统一显示为“正常备份”，补齐手动还原点及文件数量等简体中文、繁体中文、英文文案。
- 调整世界恢复确认文案，提示用户先手动保存需要保留的进度。

## 保留的保护

- 整合包更新仍保留原始文件和中断事务恢复，不会继续执行中断的更新。
- 世界及实例还原事务的中断保护保留。

本版本通过 GitHub Actions 构建，注入 OAuth client ID，并附带 Sigstore 签名文件。LF 与 Lite 真实整合包双跑的逐文件一致性验收尚未完成。
