# PCL Lite 1.7.5-pre-1

本次为 1.7.5 的首个 pre 预览版，包含 snapshot-5 的全部功能，并补上全实例索引范围及跨 Minecraft 目录的解析修正。

## 全实例索引

- 设置 → 游戏管理的“立刻创建索引”现在为 PCL 已发现的所有 Minecraft 根目录中的有效实例创建索引，包含未选中和隐藏的实例，不再只处理主页当前选中的实例。
- 创建过程显示已处理实例数、总实例数、当前实例和已处理模组文件数。单个实例或目录失败时继续处理其余项目，最后汇总失败路径；取消时保留已完成的索引。
- 共享模组目录在加载器、游戏版本及旧 Forge 子目录规则一致时只扫描一次，并分别保存各实例的缓存，避免重复解压相同模组。
- 不切换主页选中的实例或全局 Minecraft 根目录。未隔离实例使用其自身所属根目录，继承版本 JSON 也从该实例自己的 versions 目录读取，避免跨目录扫描时误读当前选中目录中的同名版本。
- 保留 42px 高的原生 PCL 按钮、32px 高的提示开关，以及“立刻创建索引 / 稍后 / 不再提示”。模组页面的缺索引提示仍只针对正在查看的实例。

## 保留的索引优化

- 待机和普通浏览不自动补建缺失关系索引；下载、更新模组后仍自动更新相关文件，兼容旧 Forge 版本子目录。
- 根据 CPU 和可用内存使用 1–8 个受控并行任务，手动创建优先于后台下载索引；后台被抢占后保存完成项并使用缓存重试。
- 顶层元数据与 SHA-1 预热并行读取，关系缓存流式压缩至临时文件后替换，减少内存复制和压缩耗时。
- 扫描期间个别文件被删除、改名、改写或拒绝访问时，记录原因并继续显示其余文件；读取保留允许删除的共享方式。

## 修改实例与模组迁移

- 包含前序快照中的修改加载器、游戏版本与现有模组迁移流程，保留备份提示、5 秒备份二次确认和 3 秒模组迁移二次确认。
- 全部选中目标模组统一预检必需依赖，迁移列表内已满足要求的构建不再重复提示或下载；提供“自动下载全部必需依赖”选项。
- 保留原生任务管理页的六阶段进度、批量下载与取消；无法完整迁移的项目保留源文件并报告，不擅自替换为其他同名项目。

## 验证与发布

- 功能提交已通过 GitHub CI 的 908 项测试、TestAll 插件构建、x64 / ARM64 构建及源码契约检查。发布版本提交另行执行 CI。
- 沿用发布工作流注入 OAuth client ID，分别生成并验证 x64 / ARM64 的 Sigstore 签名，发布页附带对应 `.sigstore.json` 文件。
- 本版仍为预览版，不替换稳定版通道。真实游戏启动、多目录 GUI 全流程及用户模组集的加速倍数尚需验收。

## 建议测试

1. 在 PCL 中添加两个 Minecraft 目录，各放置多个实例，在设置点击“立刻创建索引”，检查未选中及隐藏实例也在任务范围内。
2. 检查总体计数、当前实例名称及取消；再次创建应复用已完成缓存，主页选择和 Minecraft 根目录应保持原样。
3. 测试共享 mods 目录、不同加载器及两个根目录中同名的继承版本，确认索引和版本信息没有串用。
4. 选择“稍后”后观察待机不补建；“不再提示”应跨重启记忆，设置开关可重新启用。
5. 下载或更新模组，确认自动索引仍然生效；在测试副本中扫描时删除或改名文件，检查列表与文件操作正常。
