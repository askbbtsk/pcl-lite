# PCL Lite 1.7.5-pre-3

本次预览版包含 pre-2 的全部功能，修复修改实例的临时目录位置，以及迁移模组选择弹窗无法立即确认的问题。

## 修改实例的临时目录

- 将 `.pcl-modify-*` 安装暂存目录移至系统 Temp 下的 `PCL-Lite/InstanceModification/<任务标识>/versions/`，不再在用户 Minecraft 的 versions 中创建临时实例。
- 安装器的忽略标记、原版下载和合并输出使用明确的目标实例路径，避免某些安装步骤按版本名重新写入用户版本目录。
- 成功、失败或取消后，在安装和下载子任务释放资源后自动清理整个工作区。
- 使用独占租约区分仍在运行的任务。下次启动重试清理带有效归属标识且已解锁的系统 Temp 残留；占用、链接或归属变化时保留并记录日志。
- 清理失败时保留归属标识，以便下次重试；不删除用户实例和事务恢复资料。旧版本已遗留在用户 versions 中的目录不按名称自动删除，避免误删无法确认是否仍在使用的内容。

## 模组选择确认

- 修复“选择要迁移的候选模组”默认已勾选，却必须手动切换某项才能点击“继续”的问题。
- 列表初始化后和弹窗首次显示时同步按钮状态；默认已选中时可以立即确认。
- 按钮可用状态与最终提交使用相同的选择索引规则；空列表或全部取消勾选时仍不允许确认，不改变原有单选流程。

## 验证与发布

- GitHub CI 验证核心测试、x64 / ARM64 主程序、TestAll 及源码契约。
- 新增覆盖系统 Temp 路径、标准实例暂存布局、成功/失败/取消清理、活动任务保护、中断残留回收、归属变化、占用后重试和默认勾选确认等测试。
- 沿用发布工作流注入 OAuth client ID，为两种架构生成并验证 Sigstore 签名，发布页附对应 `.sigstore.json`。
- 真实游戏安装和 GUI 全流程仍需验收，不将 CI 通过视为全部交互已实测。

## 建议测试

1. 修改一个已备份的测试实例，确认用户 versions 中不再新增 `.pcl-modify-*`，过程中的工作文件位于系统 Temp。
2. 分别测试完成和取消后临时目录被清理；仍被其他程序占用时，关闭占用并重启启动器，检查清理重试。
3. 打开候选模组列表，默认勾选后直接点击“继续”；全部取消勾选应禁用确认，重新勾选后恢复。
