# PCL Lite 1.7.5-pre-4

本次预览版包含 pre-3 的全部修复，停止支持服务仓库的 v1 更新清单。

## 更新源

- 服务仓库删除 `update.json`，只保留 `updatev2.json` 作为更新清单，公告和插件市场索引保持。
- 启动器仅请求 v2。v2 超时、缺失、返回网页或解析失败时，不再回退请求 v1 单指针文件。
- v2 文件中直接填入旧版单指针也会被拒绝，避免变相恢复已停止的 v1 支持；多源列表和源权重规则保持。
- 发布/镜像仓库根目录用于身份校验的 `update.json` 保留，它不属于服务清单的 v1 回退。
- 现有多通道 v2 请求、镜像身份校验、按权重选择 Release、直接 GitHub Releases 后备源及下载签名验证保持。
- 更新维护文档与诊断工具，使用 `tools/verify-manifest-v2.py` 检查 v2，移除旧版回退诊断脚本。

## 验证与发布

- 新增测试确认 v2 请求失败和解析失败都只请求 `updatev2.json`，即使存在合法 v1 内容也不会使用。
- 测试 v2 有效、多源排序、个别条目跳过、旧单指针拒绝，以及服务地址和仓库身份标记用途分离。
- GitHub CI 执行核心测试、TestAll、源码契约及 x64 / ARM64 构建。发布流程注入 OAuth client ID，并生成和验证两种架构的 Sigstore 签名。
- 只支持服务仓库 v1 文件的旧客户端将无法再通过该文件获取更新指针；本次按要求停止维护该入口。
