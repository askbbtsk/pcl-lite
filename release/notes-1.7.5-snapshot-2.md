# PCL Lite 1.7.5-snapshot-2

本次为代码结构整理后的预览版本，包含 1.7.5-snapshot-1 已有的整合包制作与在线附带 PCL Light 功能。

## 相比 snapshot-1 的更改

- 拆分 30 个超过 1000 行的遗留 C# 文件，覆盖下载与安装、整合包导入导出、资源平台和本地资源、启动与实例设置、窗口导航、Lunar、Bedrock GDK、插件及 Mixin 运行时。完成拆分的入口和新增 C# 文件均控制在 1000 行以内。
- 将弹窗执行、版本 JSON 合并、资源请求、数值算法及 Lunar 消息解码等职责提取到明确命名的模块；保留原有兼容入口、类型身份和状态初始化顺序。共享状态较多的模块按职责拆分 partial，不宣称已经完全隔离所有依赖。
- CI 增加原入口与源码语法契约检查、长文件扫描，覆盖 DEBUG、CI、RELEASE、BETA 条件；修正 GDK 拆分后预处理区域边界的问题。
- TestAll 测试插件源码更新至 0.1.1，增加宿主模块及弹窗入口的只读探针、数值边界与资源目录映射检查。本次启动器发布不自动替换用户已安装的测试插件。
- 欢迎页移除当前所选实例与最近世界卡片。
- 调整关于页致谢，移除不再适用的 Bedrock 启动来源条目，加入“无条件感谢 JetBrains，特别感谢 IntelliJ IDEA”。

## 验证与测试范围

- 发布准备前的 dev 提交已通过 714 项单元测试、TestAll 构建及 x64 / ARM64 CI 构建。
- 发布继续通过 GitHub Actions 注入 OAuth client ID，为 x64 和 ARM64 程序生成并验证 Sigstore 签名，随程序提供 `.sigstore.json` 文件。
- 本次以维持现有行为为目标进行结构整理；真实游戏启动、认证交互、取消下载、插件/Mixin、Bedrock/CIK 和 Lunar 的完整 GUI 回归仍需人工测试，不能将编译和单测通过等同于全部交互已验证。
- 新讨论的实例增强、跨加载器辅助迁移及三个设置开关仍属于计划，不在本次发布中宣称已实现。

## 已知边界

- 继承 snapshot-1 的限制：当前 PCL Light 发布版导入时强制开启隔离；附带 Light 与关闭隔离的组合会提示并停止导出。
- 此版本为预发布测试版，不替换最新正式版发布标记。
