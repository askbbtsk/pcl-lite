# PCL Lite 1.7.5-snapshot-3

本次预览版加入实例管理增强、模组集合、跨加载器辅助迁移及 Prism 只读导入，并修复 Lunar 会话状态串扰。包含 snapshot-2 已有改动。

## 新增与改进

- 设置 → 启动新增三个独立默认开启的开关：启动前检查模组依赖、标注加载器不匹配的模组、按实例记忆按键与鼠标设置。使用 PCL 原生控件，补齐简体中文、繁体中文和英语。
- 依赖提示可打开对应实例的模组管理、继续或取消；不未经确认下载、启用或删除模组。不匹配标注基于已知元数据，多加载器构建及兼容桥保守处理。
- 实例概览新增体检：沿用当前版本配置及原生运行库解析，报告缺失、损坏与无法验证项；解析缓存缺失或损坏时可重建，不据旧缓存覆盖用户文件。
- 体检可明确选择仅补齐有可靠来源及校验值的缺失运行库；不覆盖已有损坏文件，提交时不覆盖并发出现的目标。
- 实例概览新增实际模组、配置及个人设置文件差异对比、重复增强身份报告和解析缓存清理。只报告差异，不自动同步；清理保留声明、个人设置记忆及事务恢复资料。
- 模组页支持将选中文件保存为本地集合，并预览复制到当前实例。来源保留，禁用后缀保留，同名不同内容不覆盖；链接、占用、缺失与取消逐项报告。
- 修改实例页新增跨加载器迁移预览，支持 Fabric、Forge、NeoForge。仅同项目明确支持目标 MC/加载器的构建生成可靠候选；创建独立新实例，未知项保留来源并报告，配置和存档默认不复制。
- 百宝箱 → 导入设置新增 Prism 实例目录只读导入。经原生安装器创建目标，保留组件标志与来源记录，按现代 Prism 组件清单顺序处理已支持补丁；不读取 Prism 全局账号或缓存。
- 目标 Java 校验与普通启动共用原有约束和选择器；不复制源实例固定 Java 选择。显式测试副本重新生成增强身份，不带入旧解析报告和未完成事务。
- 游戏文件和整合包来源记录使用统一写前日志、独立提交标记及中断恢复；恢复不续跑下载，发现外部修改时保留并报告。
- 新增增强记录、集合索引和迁移/导入暂存目录的导出过滤，避免分发本机内部状态。

## 修复

- 修复旧 Lunar 游戏的延迟退出、停止、输出及 IPC 回调覆盖新会话状态的问题；结束日志附带 PID。
- Forge 安装成功同时要求退出码 0 与既有成功标记；静默安装器取消时检查中断并结束所属进程，等待真实下载/安装任务释放后再清理迁移暂存。
- 修复禁用运行时封送时 Windows 长短路径查询的兼容问题，并统一路径别名对应的协作操作锁。

## 验证与边界

- 功能提交通过 806 项单测、TestAll 插件构建、x64/ARM64 构建，以及源码契约、共用 Java 规则和超长文件检查；发布提交另由 CI 验证。
- 发布通过既有 GitHub Actions 注入 OAuth client ID，为两个架构生成并验证 Sigstore 签名，随程序提供 `.sigstore.json` 附件。
- 真实联网安装、游戏启动、取消及 GUI/DPI 等完整交互仍需人工测试，不能将构建和单测通过等同于所有场景已验收。
- Prism 的 Quilt、未知启用组件及无法无损映射的自定义补丁会明确拒绝；不宣称任意 Prism 整合包都能无损导入。跨加载器迁移不猜测同名项目的等价关系。
- 启动器在游戏启动后直接退出时，无法驻留捕获该次游戏结束后的键鼠记忆；已有记忆保留。
- 协作锁不代表可以阻止所有外部程序写入；发现外部变化保留并报告。本次未恢复自动备份或内部回收站。
- 继承已有 Light 限制：当前 Light 导入强制隔离，附带 Light 与关闭隔离的组合仍会提示并停止导出。

详细入口及验收范围见仓库 `docs/INSTANCE-ENHANCEMENTS.md`。本版为预发布，不替换最新正式版标记。
