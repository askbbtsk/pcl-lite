# PCL Lite 1.7.6

本次正式版包含 1.7.5 hotfix-1，以及之后的全局搜索、桌面折射和实例可靠性改动。以下按最终实际行为说明。

## Ctrl+K 全局搜索

- 按 **Ctrl+K** 或点击窗口右下角搜索按钮，在当前窗口中打开搜索面板；支持多关键词、英文大小写无关匹配，上下方向键选择、Enter 打开、Esc 或点击外侧关闭。
- 搜索当前 Minecraft 目录中已加载的可见实例。正常实例进入管理页；损坏实例打开文件夹。已在实例概览中搜索打开另一实例时，同步刷新概览、侧栏和标题，避免界面仍显示旧实例。
- 搜索 Java、启动、个性化、语言、游戏管理、其他、更新、关于等设置页，以及常用导航入口。生成结果和执行命令均遵守功能隐藏配置，保留 F12 临时显示隐藏功能的规则。
- 搜索打开面板时主页选中实例的已安装模组，匹配名称、Mod ID 和文件名，包含 `.disabled`、`.old` 禁用文件。打开模组结果会在资源管理器中定位文件，不执行启用、禁用或删除。
- 模组元数据在后台读取，缓存未命中时不为搜索解压完整 Jar-in-Jar 树。关闭面板取消后续扫描；旧扫描不得回填新面板。无法解析的单个文件回退到文件名。
- 关闭按钮使用 PCL 控件，焦点在关闭按钮时 Enter / Space 只关闭，不执行当前结果。关闭后尝试恢复原输入焦点。
- 首版最多展示 60 项；只搜索当前目录的已加载实例及当前选中实例 `mods` 顶层文件。设置结果定位到页面，不定位具体开关。搜索面板主体采用普通主题材质，尚未加入整块液态玻璃折射。

感谢 **olganb666** 提交 PR #9，并完成复审修复。

## LiquidGlass 与桌面采样

- **实时桌面折射由 WGC 切换为 DXGI Desktop Duplication**，不再启动产生黄色采集边框的 WGC 会话。移除 WGC 接口、Windows SDK Contracts、CsWinRT 生成配置及相关运行依赖，不保留 WGC 回退后端。
- 各显示器使用所属显卡创建采集设备；支持显示器旋转后的区域裁剪。桌面静止但窗口移动到其他区域时，可利用持有的桌面纹理重新裁剪。
- 获取帧超时按“暂无新帧”处理；设备、显示器或桌面状态变化沿用有限重建流程，最终不可用时显示静态材质。会话异步退役，不让窗口线程等待 GPU 回读；测试可等待原生资源实际释放完成。
- **移动或缩放窗口时改用静态磨砂**，暂停桌面采样，松开后重建并等新帧恢复实时折射。拖动中关闭玻璃后，松手不会重新启用采样。
- 浅色桌面材质使用白色衬色，深色使用深色衬色，并加强桌面模式的材质对比度；采样像素本身不反色，普通壁纸模式保留原材质强度。
- 反馈等侧栏导航的刷新按钮向胶囊内侧收进，避免贴住或超出圆角边缘；关闭玻璃恢复原按钮边距。
- 修复颜色动画忽略窗口和插件页面资源的问题：动画目标色从目标控件的资源作用域查找，与完成后恢复的动态资源保持一致。

**截图限制仍然存在：**实时桌面折射期间保留窗口截图排除，避免采样启动器自身形成递归画面。需要截图或录屏包含启动器时，请先关闭“实时桌面折射”。本版本没有实现“持续折射同时被外部截图捕获”。

**不透明度行为：**开启玻璃后，“背景 / 窗口不透明度”仅改变启动器主题底色及图片/视频背景，不淡化实时桌面采样、玻璃、文字和 PCL Lite 徽标；关闭玻璃后恢复普通整窗不透明度。提示文案已同步说明。

## 实例修改与数据保护

- 实例版本 JSON 解析增加覆盖完整递归链的循环检测，拒绝自引用、A→B→A 等循环和超过 64 层的继承。失败不保留未完成的 JSON 缓存，后续修复文件后可以重新读取。
- 合并继承项前克隆父 JSON，保留现有字段与数组合并规则，不把子实例覆盖写回父对象或父文件。
- **同一加载器仅升级构建号也统一走事务流程**：系统临时目录暂存、产物校验、预览确认、提交及失败回滚；不再直接落入旧的修改安装分支。
- 明确选择的 Fabric API、Legacy Fabric API、OptiFabric 替换与实例核心文件纳入同一事务，原文件字节按现有规则保留为禁用备份；同一个源 API 不再同时交给显式替换和通用迁移。
- 修改入口和任务校验实例所属 Minecraft 根目录；与当前全局目录不一致时，在写入前拒绝，防止锁定、验证或刷新错误目录。跨目录修改前需先切换到对应 Minecraft 目录。
- 重置实例使用自己的备份提示，不再误弹“修改加载器”的五秒确认。文案说明核心文件备份位置及手工 JSON/JAR 修改可能被重新安装替换。
- 模组迁移候选列表允许全部取消勾选后继续，明确表示此次不迁移候选项；取消按钮仍取消任务。其他多选弹框继续保持原有至少选择一项的默认规则。
- 保留原有修改后按目标环境自动选择 Java 的行为，保留祖先目录 Junction/Symlink 写入防护；没有放宽用户文件保护范围。

## 包体与发布检查

- 继承 1.7.5 hotfix-1 的背景分层修复和图形依赖精简，并进一步移除 WinRT 投影。继续提供 x64、ARM64 单 EXE，依赖现有 .NET Desktop Runtime，不另行下载玻璃组件。
- 发布流水线检查两种架构正式 EXE 不超过 **30,000,000 字节**，并检查没有旁挂完整 Windows SDK 或独立 WinRT.Runtime。
- 新增原生交互控件门禁，同时检查 XAML 和四种配置下的 C# 创建代码；违规输出文件、行号及 error，阻断后续发布。已有安全密码输入、只读日志及 PCL 模板内部用途使用逐项内容指纹例外，不整目录放行。
- 保留原插件接口签名及多选默认值，补充插件资源作用域、继承错误和跨目录修改边界说明。

## 验证与实机检查范围

发布前执行完整 Core 单测、源码兼容契约检查、原生控件门禁和 x64 / ARM64 构建。新增回归覆盖实际 JSON getter 的循环/正常合并、修改事务、插件局部颜色资源、拖动暂停与恢复、DXGI 原生帧获取/释放和旋转裁剪。

上述检查不能替代所有显卡、多显示器、DPI、输入法和真实加载器网络安装的端到端验收。更新后建议重点检查 Ctrl+K 实例切换与关闭、拖动磨砂恢复、同加载器升级和零项迁移。
