# PCL Lite 1.7.7 hotfix-1

- 修复开启实时桌面折射后，窗口四个圆角外侧出现矩形毛边的问题：后方的采样辅助窗口此前仍按矩形绘制，会从启动器的透明圆角处露出。
- 辅助窗口现在按照启动器实际的 WPF 圆角裁剪，在设备像素中换算 DPI，并向内收 1 个物理像素，避开抗锯齿边缘；四个角统一处理。
- 开启玻璃时圆角从普通样式切换到玻璃样式，辅助窗口立即同步更新，无需先拖动或缩放窗口。尺寸与 DPI 变化继续同步。
- 关闭采样时释放圆角观察器与原生窗口区域，避免重复订阅及区域资源泄漏。
- 保留 1.7.7 的实时折射、截图、录屏和搜索按钮隐藏设置，不改变 PCL 底层渲染。
- 新增原生窗口区域与裁剪传递回归测试，覆盖四角、100% / 125% / 150% / 200% 缩放、不同窗口尺寸、玻璃圆角切换及矩形调用恢复。相关 19 项本地测试通过；另验证实时折射、截图、最小化/恢复、拖动暂停/恢复及快速开关。

提供 x64 / ARM64 正式构建，沿用 OAuth 注入、Sigstore 签名与验签流程。
