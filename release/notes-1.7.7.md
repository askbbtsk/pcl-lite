# PCL Lite 1.7.7

本次正式版主要解决液态玻璃与截图、录屏的兼容问题，并补齐全局搜索的显示设置。包含 1.7.6 hotfix-1 / hotfix-2。

## 实时桌面折射支持截图和录屏

- 实时桌面折射默认采用独立的系统采样窗口，采样时只过滤启动器自身与采样窗口，不再通过全局窗口捕获排除隐藏启动器。
- 开启实时折射后，可以同时截图、录制启动器。无需环境变量、命令文件或单独的实验启动入口。
- 采样不使用 WGC，不产生其黄色捕获边框；启动器不保存或上传采样画面。
- 继续使用原有的玻璃材质与 shader，没有更换 PCL 的底层渲染。背景不透明度仍只影响底色与图片/视频，不影响实时桌面、玻璃、文字和徽标。
- 拖动、缩放窗口时暂停采样并使用磨砂，松开后恢复；最小化暂停，关闭后释放采样窗口、工作线程和图形资源。
- 设置名称、说明和开启确认已同步修改，移除“需要截图时先关闭实时折射”的旧提示。现有性能确认、画质预设及帧率设置继续有效。

## 界面修复与搜索设置

- 修复切换主题或重新开启玻璃后，旧主题动画完成时把蓝色实底条重新刷到标题栏、覆盖玻璃效果的问题。约束仅作用于标题栏；关闭玻璃后恢复普通主题背景。
- 修复液态玻璃说明、桌面采样兼容提示和采样状态文字可能回落为黑色的问题，明确绑定主题画笔，并在切换主题、开启和关闭玻璃后保持可读。
- “设置 → 个性化 → 基础”新增“显示右下角全局搜索按钮”，默认开启，关闭后立即隐藏并保存。Ctrl+K 仍可打开全局搜索；开关使用 PCL 控件，行高 28。
- 简体中文、繁体中文、英语设置文案与启动器内版本说明同步更新。

## 包含的 1.7.6 热修复

- 修复搜索入口和关闭按钮的事件参数与 PCL 控件不匹配，造成主窗口 XAML 加载失败、启动停滞的问题。
- 主窗口初始化未完成时跳过页面快捷键和鼠标侧键操作，避免二次空引用异常。
- 修复进入实例设置等子页面后主导航玻璃栏残留，与子页标题重叠的问题；返回主页面正确恢复。
- 发布构建检查实际编译程序集与 XAML 中的事件绑定，防止只编译通过却在启动时失败。

## 验证范围

- 本机已验证完整启动器实时折射期间的截图与连续画面捕获；保存 240 帧并收到 70 次动态更新，覆盖搜索、导航和滚动。
- 已验证最小化、拖动暂停/恢复、连续开关及采样资源释放；用户已试用并确认本地修复版。
- 不将这些结果等同于所有 Windows、显卡、HDR、多屏组合和录屏软件都已实测；采样不可用时按现有流程回退静态材质。
- x64 / ARM64 通过 Release 流程构建，沿用 OAuth 注入、Sigstore 签名与验签，单个程序维持 30 MB 体积上限。
