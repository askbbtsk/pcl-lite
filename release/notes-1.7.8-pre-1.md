# PCL Lite 1.7.8-pre-1

本次为 1.7.8 预览版，包含 snapshot-1 / snapshot-2 的主题系统及以下修正。

## 主题下拉与恢复入口

- 修复 Soft Slate 等主题的选择框模板有弹出列表、却没有鼠标展开按钮，导致点击后无法看到选项的问题。
- 兼容已安装的旧模板：在缺少展开按钮时由宿主接管鼠标展开；正常 PCL 模板保持原有接线，可编辑框仍保留文本区域的编辑行为。不改写用户主题文件。
- “外观主题包”的恢复选择框固定使用内置 PCL 样式，第三方主题不能覆盖这一恢复入口。
- 第一项固定为可用的“内置主题”，选择即可恢复原有外观；损坏、缺失的主题不能被误选为默认项。
- 设置位置仍在液态玻璃下方，保留注释 XAML 示例、拖拽安装、手动重载及 15 秒确认恢复。

## 验证

- 新增回归检查：旧自定义模板的鼠标展开、恢复选择框的展开接线、内置项位于首位，以及损坏/已移除主题下的选择状态。
- 测试不显示实际弹出窗口，不操作用户桌面；保留输入框、可编辑下拉框、卡片等主题切换回归检查。
- 本次只跑主题相关单测和发布所需的构建/烟测，未跑全量单元测试。
- 发布流程执行 x64 / ARM64 构建、OAuth Client ID 注入和 Sigstore 签名验证。
