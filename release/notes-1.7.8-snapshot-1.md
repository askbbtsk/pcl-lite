# PCL Lite 1.7.8-snapshot-1

本次为快照预览版，重点提供可编辑的 XAML 外观主题系统及主题学习示例。

## 外观主题包

- 基于原有主题服务和 PCL 控件扩展视觉接口，支持按钮、卡片、输入框、选择框、列表、滚动及提示等控件的模板、字体、圆角、阴影、图标和材质资源。
- 个性化设置新增主题列表、文件和目录安装、打开主题文件夹、手动重新加载与恢复内置主题；操作行最小高度为 38 DIP。
- 可将主题 XAML 或 ZIP 拖入启动器，提示确认后安装并立即预览；主页 XAML 保留原有导入行为。
- 切换后提供 15 秒确认时间。未确认、取消或加载失败时恢复此前外观；上次加载或预览未完成时，下次以内置主题进入。
- 主题可声明兼容的启动器版本。版本不匹配时可强制预览；确认按当前启动器版本和主题内容记住，任一变化后重新提醒。
- 主题声明是否支持液态玻璃，不支持时暂停效果并保留用户开关。主题不能自行授予桌面采样权限。
- 加载前检查允许的 XAML 类型、资源引用、必需编辑部件、路径与展开预算；拒绝主题中的代码、外部程序集和远程资源地址。

## 注释示例与学习入口

- 新增 `docs/theme-examples/StarterTheme.xaml`，可直接拖入安装。中文注释逐项说明圆角、边距、字体、颜色、按钮状态、阴影、输入框部件和图标替换。
- 同目录提供编辑教程，说明使用记事本或 VS Code、UTF-8 编码、文件扩展名，以及源文件和已安装副本的区别。
- 主题设置新增“打开注释示例”：把同一份 XAML 与说明导出到 `PCL/ThemeExamples/Starter` 并打开文件夹；重复点击不覆盖用户已编辑文件，也不会自动安装。
- 随附完整主题 API 文档及 SoftSlate 浅色／深色／玻璃多文件示例。

## 切换与恢复

- 保留原 PCL 控件的点击、输入、选择和折叠逻辑；切换可编辑下拉模板时释放旧编辑器订阅，避免重复通知。
- 同步按钮警告色、导航选中／取消、卡片展开／折叠状态到主题呈现层。
- 退出主题后恢复当前用户的背景和字体继承状态，避免恢复到过期快照。
- 兼容并保留 dev 已有的基岩版致谢及历史 MIT 许可声明。

## 验证

- 文件安装、XAML 解析、版本确认、路径越界、重复／链接 ZIP、缺少资源、循环及指数展开、预览时限与恢复状态均有专项测试。
- 生产按钮、输入框、卡片、可编辑下拉框反复切换烟测，检查内容、文本选区、编辑和事件订阅恢复；同时检查示例导出与文档逐字节一致、不覆盖编辑。
- GitHub CI 运行完整单测、x64／ARM64 构建、原生控件检查及 WPF 事件／主题烟测。发布工作流注入 OAuth Client ID，并生成及验证 Sigstore 签名。
- 真实输入法、不同 DPI、玻璃与第三方主题的最终视觉效果仍需用户验收；快照版不代表任意 XAML 模板都兼容。
