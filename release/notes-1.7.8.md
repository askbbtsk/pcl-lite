# PCL Lite 1.7.8

本次正式版汇总 1.7.8 各预览版的改动，并新增 Lunar 首次进入提示。

## Lunar 账号风险提示

- 首次进入 Lunar 页面前显示账号安全提示：Lunar 原版启动器明文保存 Refresh Token，PCL Lite 为兼容使用相同账号文件格式，使用该功能可能导致账号凭据泄露。
- 确认按钮从弹窗实际显示后倒计时 3 秒，取消按钮始终可用；取消后留在原页面，不初始化 Lunar 页面或触发该页面的账号预热。
- 用户确认知晓后保存本机记录，以后进入不再提示；取消或关闭窗口不视为确认。
- 保留 Lunar 现有登录、账号文件与续期方式；本次没有修改 token 脱敏或账号存储。

## 自定义外观主题

- 基于现有 PCL 控件和主题服务提供 XAML 主题包，支持控件模板、颜色、字体、圆角、阴影、图标与材质资源。
- 个性化设置中的“外观主题包”位于“液态玻璃”下方，提供主题选择、安装、打开文件夹和重新加载；下拉首项为“内置主题”。
- 支持拖入主题 XAML 或 ZIP，确认后安装；保留原有主页 XAML 导入流程。
- 应用或重载后进入 15 秒预览，取消、超时或失败时恢复此前外观；未完成加载后的下次启动以内置主题进入。
- 主题可声明启动器版本兼容范围，版本不匹配时提示并允许强制预览；不支持玻璃的主题暂停玻璃效果，同时保留用户原设置。
- 提供带中文注释的 XAML 示例、编辑教程及主题接口文档，设置内可打开示例，重复导出不覆盖用户编辑。
- 修复部分自定义选择框点击无法展开的问题，并固定主题恢复选择框使用 PCL 内置样式。

## 体积与错误隐私

- 改用 Windows 系统 SQLite，移除内置原生 SQLite 引擎；保留 Windows 10 1809（17763）及以上的兼容目标。
- 哈希缓存写入兼容旧版 SQLite，保留不同哈希算法的缓存结果与事务保护。
- 修复启动器初始化失败、完整异常和普通错误弹窗中的用户名打码；支持带空格、中文用户名、转义路径及迁移到其他位置的用户目录。
- 启动器日志写入及历史日志导出遵循现有用户名打码设置。

## 验证

- 发布前运行完整单元测试、源码契约检查、x64 / ARM64 构建及原生控件、WPF 事件、主题控件烟测。
- 发布流水线注入 OAuth Client ID，并生成、验证 Sigstore 签名。
- 旧版 SQLite 3.23.2 已单独验证 .NET 接入、读写、哈希合并、WAL 和事务回滚；这不等同于在所有旧版 Windows 整机环境完成实测。
