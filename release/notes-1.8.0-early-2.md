# 1.8.0-early-2

## Lunar

- 好友状态统一使用“好友系统”，同步简体中文、繁体中文和英语。
- 改善自定义 Java agent 的兼容性：带 `-javaagent` 启动时，默认关闭 Lunar 的预烘焙类缓存，避免自定义 Lunar 目录中的旧缓存干扰 agent 的类转换。普通启动保持原缓存行为；用户显式填写的缓存开关仍优先。
- 附加 JVM 参数继续按独立参数传入 Java，保留路径中的空格、中文以及多个 agent 的先后顺序，不修改 agent 或模组文件。

## 验证

- 新增 6 项 JVM 启动参数回归测试，覆盖 agent 透传、带空格与中文的路径、多个 agent、缓存设置优先级、普通启动及官方参数覆盖。
- 本地 Lunar 相关测试 22 项通过；独立 Java 探针确认 Lunar 原生缓存开关生效。未实际启动游戏验证第三方 agent 的游戏内功能。
- 发布工作流对同一提交执行完整 CI、x64/ARM64 构建与签名；失败则停止发布。
