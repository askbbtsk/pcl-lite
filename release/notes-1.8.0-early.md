# 1.8.0-early

## IPv6 直连多人联机

- 修复 Minecraft 局域网列表使用本机 IPv4 地址连接时被代理拒绝的问题；代理接受本机网卡和回环地址，拒绝非本机来源。
- BSK 邀请码和 ACK 回执码需要双向确认。房主可逐个放行好友；重复提交同一 ACK 不会重复添加。
- 房主可以单独断开某位好友，不影响其他好友。被断开的会话回执失效，好友重新加入后可再次放行。
- 游戏数据仍按 Minecraft 原始载荷转发。隧道控制包使用分方向 HMAC-SHA256 验证、防重放计数器和窗口；不会额外加密游戏协议。
- 房主关闭 PCL 房间后，连接者的隧道心跳超时会将状态切换为断开。房主关闭已广播的 Minecraft 局域网世界后，广播过期状态也会通知连接者；重新开放后连接状态恢复。
- 离开页面时邀请码和回执输入会清空；代码仅在用户点击复制时写入剪贴板。移除开房时的离线确认框，PCL 账户状态只用于显示，不改变游戏端认证策略。
- 修复旧版 Minecraft 在 Windows 上使用系统代码页广播局域网世界名称时出现乱码的问题。
- 联机页面文案同步为“开启新房间”“当前连接好友”和“暂无好友连接”，并简化邀请、回执操作提示。

## Lunar

- Lunar IPC 固定使用 `127.0.0.1:28190`。端口被占用时按 Lunar 启动器已占用处理，把原端口交给游戏，不接管 IPC，也不改用 `28191`。
- 启动 Lunar 游戏前清除上次运行的 `latest.log` 和滚动压缩日志；保留 `logs/game/config.xml` 与其他文件。

## 版本与界面

- 修复同一基础版本下 alpha 被错误排在 snapshot 之上的问题；不同基础版本仍先比较版本号。
- 精简简体中文、繁体中文和英语共 61 组界面文案，涉及液态玻璃、主题、基岩版、模组索引、整合包更新与导出、启动选项和工具提示。
- 从关于页面移除重复的旧版发布说明。
- 测试运行器最多并行执行 4 个测试类；涉及全局状态或共享资源的测试保持独占执行。

## 验证

- 增加心跳断开、局域网世界关闭/恢复、旧系统代码页广播、Lunar IPC 固定端口和日志清理回归测试。
- 本地相关测试：31 项通过。
- 发布工作流会对同一提交执行完整 CI、x64/ARM64 构建与签名；任一步失败都会停止发布。
