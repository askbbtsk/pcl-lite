# 1.8.0-pre-1

## IPv6 直连多人联机

- 修复 Minecraft 局域网列表通过本机局域网 IPv4 地址连接时被拒绝的问题。房客代理现在接受本机网卡地址和回环地址，并拒绝来自非本机地址的连接。
- BSK 邀请码和 ACK 回传码不再自动读取剪贴板，也不再自动复制；用户明确点击复制按钮后才写入剪贴板。
- 离开页面、切换房主/房客模式、提交邀请码或回传码、断开连接后，输入框会清空，避免复用上一次的代码。
- 移除每次开房时询问是否允许离线的弹窗。状态标记改为镜像房主当前的 PCL 账户类型；该标记不改变 Minecraft 的认证策略，实际能否进入仍由房主游戏端决定。
- 更新简体中文、繁体中文和英语的相关按钮、输入提示和状态说明。

## 验证

- 通过局域网 IPv4 地址访问房客代理并逐字节回显的回归测试。
- 非本机来源被代理入口拒绝的测试。
- 直连多人 ACK 与并发游戏数据传输相关测试。
