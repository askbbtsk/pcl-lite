# 1.8.0-snapshot-3

## 更新版本排序

- 修复相同基础版本下 alpha 被排在 snapshot 之上的问题。alpha 归入最不稳定频道，snapshot 高于 alpha；不同基础版本仍先比较主版本号。

## IPv6 直连与短码

- BSK 邀请码、ACK 回执码均缩短至含前缀 30 字符，正文为 26 个 GB2312 一级汉字，支持复制时混入空白与换行。界面同步说明两类代码的长度及复制方式。
- 房间使用随机 16 字节能力密钥；ACK 使用独立认证码，绑定房间、好友地址、端口和会话，不在 ACK 中重复分享能力密钥。4 位复制校验只帮助检查输入，不能代替认证。
- 必须通过 BSK/ACK 双向确认。房主可连续放行多个好友，重复提交同一个 ACK 不重复创建连接，加入新好友不替换已经连接的好友。
- UDP 增加分方向 HMAC-SHA256 认证、计数器及防重放窗口，拒绝篡改、错误房间和未放行端点的数据包。房间密钥不在 UDP 链路上传输。
- 游戏原始载荷保持原样，不额外加密；邀请码仍需通过可信聊天渠道分享。
- **协议已更新：双方均需更新后重新生成邀请码与回执码，旧码不兼容。**

## 测试与发布

- 单元测试改为最多 4 个测试类并发；涉及全局配置、WPF、SQLite 全局连接池及进程总分配量的测试独占执行。
- 修复测试产物与源码不在同一磁盘时的仓库定位，便于把临时产物放到 E 盘。
- 增加短码、认证篡改、重放、多人连接与数据传输回归测试。
- 发布继续要求同一提交通过完整 CI、x64 与 ARM64 构建；CI 失败停止发布。
