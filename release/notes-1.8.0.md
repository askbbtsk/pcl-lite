# PCL Lite 1.8.0

本次更新汇总 1.7.9-hotfix-4 之后的用户可见改动。

## 邀请码联机

- 新增独立联机页面，提供“开启新房间”和“我要进房间”入口，支持 IPv6 邀请码直连。
- 检测 Minecraft 已开放的局域网世界，并修复旧版 Minecraft 在 Windows 上广播中文世界名时出现乱码的问题。
- 加入后可通过 Minecraft 局域网列表进入，修复本机 IPv4 连接被代理拒绝的问题。
- 邀请码与回执码均为含前缀 30 字符，使用常用汉字编码，粘贴时可包含空格和换行。
- 加入房间必须使用 BSK 邀请码，并由房主放行好友返回的 ACK 回执码。
- 支持多位好友加入。房主可以分别断开指定好友，不影响其他连接；重复放行同一回执不会重复建立连接。
- 被主动断开的好友需要重新连接、生成新回执，旧回执不能再次加入。
- 房主关闭房间后，连接者会在心跳超时后更新为断开；局域网世界停止广播时也会更新状态，重新开放后恢复。
- 邀请码和回执码不再自动读取或写入剪贴板，仅在点击复制按钮时写入。输入内容会在离开页面、切换身份、提交或断开后清空。
- 删除开房时的离线询问，账号标记随房主当前账号状态显示；不改变 Minecraft 自身的会话验证规则。
- 为隧道增加认证、防篡改与防重放检查，游戏载荷保持原样，不额外加密。

**新旧邀请码协议不兼容，所有参与者更新后需重新生成邀请码与回执码。**

## Lunar

- 修复附加 `-javaagent` 参数在自定义 Lunar 目录下无法正确生效的问题。
- 使用 Java agent 时默认关闭 Lunar 预烘焙类缓存；没有 agent 时保持原行为，显式指定的缓存开关仍然优先。
- 保留多个 agent 的顺序，支持参数中的空格和中文路径，不修改用户的 agent 或模组文件。
- IPC 固定使用 `127.0.0.1:28190`。端口已被占用时不再改用其他端口接管，游戏继续连接原端口。
- 每次启动 Lunar 前清理日志目录中的 `latest.log`、`ichor-boot.log` 和顶层 `.log.gz` 归档，保留日志配置及其他文件；清理失败时记录警告，不阻断启动。
- 接受新一次启动时同步清空启动页的上次输出，避免旧日志混入本次启动；拒绝重复启动时保留当前日志。
- 好友连接提示统一使用“好友系统”，修正原有“后端”文案。

## 更新与界面

- 修复同一基础版本下 alpha 被判断为高于 snapshot 的问题；不同基础版本仍优先比较基础版本号。
- 联机入口接入主导航及折叠设置，适配液态玻璃侧栏样式。
- 精简简体中文、繁体中文、英语共 61 组界面说明，覆盖联机、液态玻璃、自定义主题、基岩版、模组索引、整合包更新与导出等页面。
- 修正回执码、复制邀请码、本地整合包更新和索引初始化的说明。
- 移除关于页已过时的发布说明。

## 验证与发布

- 发布流程要求同一提交的完整 CI 检查通过后，再构建、签名和发布 x64、ARM64 正式版。
- 自动回归覆盖邀请码编解码、ACK 校验、数据篡改与重放、多人传输、断开处理、版本排序和 Lunar JVM 参数。
- 测试运行器最多并行执行 4 个测试类，共享状态相关测试保持独占执行。

联机自动测试覆盖本机回环传输；不同网络、路由器和运营商环境下的公网连接仍需实际验证。
