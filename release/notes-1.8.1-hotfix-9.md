# PCL Lite 1.8.1-hotfix-9

## 账号与 Lunar

- 修复 Lunar 社交服务登录、断开和重试时的异常处理。
- 修复切换聊天、刷新历史消息时的状态错乱，保留刷新期间收到的新消息。
- 串行处理账号读取和写入，避免读取到本次账号更新的中间状态。
- 为 Lunar IPC 增加消息总长度限制和网页来源检查，保留原生游戏连接方式。
- 修复微软登录方式切换后仍沿用旧令牌签发者的问题，以及 PKCE 登录参数编码错误。

## 联机

- 修复选择性确认提前释放发送窗口，以及断线后持续重传、发送任务无法结束的问题。
- 保留多好友、单独断开和正常半关闭；超时仅结束受影响的数据流。
- 局域网检测仅接受本机世界广播，避免其他设备的广播影响本机端口。
- 修复旧版服务器信息中的中文解码，限制异常服务器响应大小。

## 文件与缓存

- 修复原生库解压、CurseForge 覆写目录、基岩版容器解包及 MCP 文件操作中的路径越界问题。
- 修复组件缓存参数绑定、缓存过期清理、共享文件引用和覆盖后的旧文件释放。
- 修复重启后无法释放缓存文件、滑动过期不续期以及不可回退流保存为空的问题。
- 缓存数据库自动升级，保留已有条目。
- 修复配置延迟保存不执行，以及相同实例路径被创建为多份配置缓存的问题。
- 修复基岩版下载校验失败后重复使用损坏文件、未完成安装被显示为已安装的问题。

## 自定义页面与界面

- 修复不支持的自定义事件导致主页或帮助页 XAML 损坏，保留其余正常内容。
- 阻止自定义页面加载未经检查的外部资源字典或访问静态对象。
- 自定义下载确认显示保存位置，保持原有参数顺序。
- 修复背景音乐切歌后暂停、播放列表并发访问以及视频停止后文件未释放的问题。
- 修复提示框重复挂钩、服务器描述动画未停止、模糊控件事件残留和瀑布流无限宽度布局错误。
- 修复拖入带加号的文件路径、普通 XAML 被主题处理提前拦截的问题。

## 更新与稳定性

- 修复更新辅助程序的清理和回滚边界，保留下载校验及签名身份要求。
- 签名校验使用启动器的网络设置；更新通道拒绝网关返回的错误网页，并为备用源保留等待时间。
- 插件重启先等待旧启动器退出，避免被单实例检查拦截。
- 修复命名管道、HTTP 连接取消、Java 扫描与游戏日志监听中的资源和并发问题。
- 收紧 MCP 凭证读取、配置写入和浏览器来源边界。
