# PCL Lite 1.8.1

## Wallpaper Engine 背景

- 在「个性化 → 自定义图片／视频背景」加入「跟随 Wallpaper Engine 壁纸」。
- 支持视频、Scene 场景和网页壁纸，使用 Wallpaper Engine 自身的渲染能力，不向 Lite 内置浏览器或 Scene 引擎。
- 增加 25%–100% 清晰度设置，默认 50%；清晰度会影响独立壁纸渲染分辨率。
- 自动跟随当前用户和屏幕的壁纸分配；切换壁纸后重新加载。
- 最小化、游戏期间暂停和关闭跟随时释放采集与独立渲染窗口；WE 不可用时恢复原背景并重试。
- 液态玻璃使用 WE 壁纸背景，暂停原桌面采样；关闭后恢复原桌面折射设置。
- 修复 WE 设置命令 JSON 转义导致的退出码 4、辅助窗口出现在左上角、高 DPI 尺寸错误和失败时反复创建窗口。
- 修复关闭玻璃后 WE 背景外侧白边，统一保留当前圆角的原生窗口裁剪。

壁纸由 WE 独立播放，播放进度可能与桌面不同，会增加资源占用。

## Lunar

- Lunar 使用官方共享 `installation-id`；未安装官方启动器时可以按官方格式创建兼容标识，不写死用户 UUID。
- 首次创建安装标识时显示提示；读取或保存失败不会使用临时标识继续启动 IPC。
- 游戏内 `RefreshAccount` 会在返回成功前按请求 UUID 更新 `accounts.json` 当前账号标记，支持账号来回切换。
- 后台令牌续期不会误切换当前账号；目标账号不匹配或切换失败时不报告成功。
- Lunar 运行日志支持在日志框内滚动，鼠标滚轮不会再带动外层页面。

## 索引与稳定性

- 索引创建进度合并高频更新，避免挤占鼠标输入；取消按钮立即通知后台任务，已完成索引仍保留。
- 精简实时桌面折射说明，移除与用户无关的截图和录屏实现描述。
- 插件市场和已安装插件左侧导航统一使用 PCL 玻璃导航样式，修复方形选中框、旧选中条覆盖和圆角不一致。
